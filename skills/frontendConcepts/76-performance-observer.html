Frontend Concepts / PerformanceObserver API

PerformanceObserver API

The unified browser API for non-intrusively subscribing to performance entries — from paint timings to long tasks to resource loads — without polling the performance timeline.

Intermediate Performance Web API
📡 Analogy: Event-Driven Monitoring vs Polling

Before PerformanceObserver, measuring performance was like checking your mailbox every 5 minutes. PerformanceObserver is like getting a push notification the moment mail arrives — no wasted trips, no missed deliveries, and you can filter to only get notifications about packages (not junk mail).

The Problem: Why Not Just Use performance.getEntries()?

// OLD WAY: Polling — wasteful, misses entries, races with buffer limits
setInterval(() => {
    const entries = performance.getEntriesByType('resource');
    // Problem 1: Returns ALL entries ever (growing array)
    // Problem 2: Buffer has a limit (150 resources default) — overflow = lost data
    // Problem 3: No way to know which entries are new since last check
    // Problem 4: Polling itself costs CPU time
    processNewEntries(entries);
}, 1000);

// NEW WAY: PerformanceObserver — push-based, efficient, no overflow risk
const observer = new PerformanceObserver((list, obs) => {
    // Called with ONLY new entries since last callback
    // No duplicates, no polling, fires asynchronously in idle time
    for (const entry of list.getEntries()) {
        processEntry(entry);
    }
});
observer.observe({ type: 'resource', buffered: true });

How It Works Internally

The Performance Timeline Architecture

// The browser maintains a "Performance Timeline" — a stream of entries
// Each entry has: name, entryType, startTime, duration
//
// ┌─────────────────────────────────────────────────────────┐
// │           Browser Performance Timeline                   │
// │                                                         │
// │  Entry Types:                                           │
// │  ┌──────────┐ ┌────────┐ ┌──────────┐ ┌─────────────┐  │
// │  │navigation│ │resource│ │  paint   │ │  longtask   │  │

// │  ┌──────────┐ ┌────────┐ ┌──────────┐ ┌─────────────┐  │
// │  │  mark    │ │measure │ │  event   │ │layout-shift │  │
// │  └──────────┘ └────────┘ └──────────┘ └─────────────┘  │
// │  ┌──────────────────────┐ ┌──────────────────────────┐  │
// │  │largest-contentful-...│ │first-input              │  │
// │  └──────────────────────┘ └──────────────────────────┘  │
// │                                                         │
// │  Observers subscribe to specific types                  │
// │  Entries are DISPATCHED to matching observers            │
// └─────────────────────────────────────────────────────────┘

Observer Lifecycle and Buffered Mode

// The 'buffered' option is CRITICAL for late-loading analytics scripts

// Scenario: Your analytics script loads 3 seconds after page start
// Without buffered: you miss LCP, FCP, navigation timing — all fired earlier
// With buffered: observer immediately receives ALL past entries of that type

const lcpObserver = new PerformanceObserver((list) => {
    const entries = list.getEntries();
    // With buffered:true, first callback includes entries from BEFORE observer was created
    const lastEntry = entries[entries.length - 1];
    console.log(`LCP: ${lastEntry.startTime}ms`, lastEntry.element);
});

// buffered:true = "give me past entries too" (replay from buffer)
lcpObserver.observe({ type: 'largest-contentful-paint', buffered: true });

// IMPORTANT: buffered only works with single-type observe()
// This will NOT buffer:
// observer.observe({ entryTypes: ['resource', 'longtask'] })
// Use separate observers for each type when you need buffering

Complete Real-World Implementation: Web Vitals Collector

// Production-grade metrics collection (similar to web-vitals library)

class WebVitalsCollector {
    #metrics = {};
    #observers = [];

    constructor() {
        this.#observeLCP();
        this.#observeFID();
        this.#observeCLS();
        this.#observeLongTasks();
        this.#observeResources();
        
        // Report metrics when page is being unloaded
        // visibilitychange is more reliable than beforeunload on mobile
        document.addEventListener('visibilitychange', () => {
            if (document.visibilityState === 'hidden') {
                this.#flush();
            }
        });
    }

    #observeLCP() {
        const obs = new PerformanceObserver((list) => {
            const entries = list.getEntries();
            // LCP can fire multiple times — only the LAST one before user input matters
            const last = entries[entries.length - 1];
            this.#metrics.lcp = {
                value: last.startTime,
                element: last.element?.tagName,
                url: last.url, // For images
                size: last.size
            };
        });
        obs.observe({ type: 'largest-contentful-paint', buffered: true });
        this.#observers.push(obs);
    }

    #observeFID() {
        const obs = new PerformanceObserver((list) => {
            const entry = list.getEntries()[0]; // Only first input matters
            this.#metrics.fid = {
                value: entry.processingStart - entry.startTime, // Input delay
                name: entry.name // 'pointerdown', 'click', etc.
            };
        });
        obs.observe({ type: 'first-input', buffered: true });
        this.#observers.push(obs);
    }

    #observeCLS() {
        let clsValue = 0;
        let sessionValue = 0;
        let sessionEntries = [];

        const obs = new PerformanceObserver((list) => {
            for (const entry of list.getEntries()) {
                // Only count shifts without recent user input
                if (!entry.hadRecentInput) {
                    const firstEntry = sessionEntries[0];
                    const lastEntry = sessionEntries[sessionEntries.length - 1];

                    // Session window: max 5s gap, max 1s duration
                    if (sessionValue &&
                        entry.startTime - lastEntry.startTime < 1000 &&
                        entry.startTime - firstEntry.startTime < 5000) {
                        sessionValue += entry.value;
                        sessionEntries.push(entry);
                    } else {
                        sessionValue = entry.value;
                        sessionEntries = [entry];
                    }

                    // CLS = largest session window value
                    if (sessionValue > clsValue) {
                        clsValue = sessionValue;
                        this.#metrics.cls = { value: clsValue };
                    }
                }
            }
        });
        obs.observe({ type: 'layout-shift', buffered: true });
        this.#observers.push(obs);
    }

    #observeLongTasks() {
        const longTasks = [];
        const obs = new PerformanceObserver((list) => {
            for (const entry of list.getEntries()) {
                longTasks.push({
                    duration: entry.duration,
                    startTime: entry.startTime,
                    // Attribution tells you WHAT caused the long task
                    attribution: entry.attribution?.[0]?.containerName
                });
            }
            this.#metrics.longTasks = longTasks;
        });
        obs.observe({ type: 'longtask', buffered: true });
        this.#observers.push(obs);
    }

    #observeResources() {
        const obs = new PerformanceObserver((list) => {
            for (const entry of list.getEntries()) {
                // Track slow resources (>1s) for debugging
                if (entry.duration > 1000) {
                    console.warn(`Slow resource: ${entry.name} (${entry.duration}ms)`);
                }
            }
        });
        obs.observe({ type: 'resource', buffered: true });
        this.#observers.push(obs);
    }

    #flush() {
        // Disconnect all observers to finalize metrics
        this.#observers.forEach(obs => obs.disconnect());
        
        // Use sendBeacon for reliable delivery during page unload
        const payload = JSON.stringify(this.#metrics);
        navigator.sendBeacon('/api/vitals', payload);
    }
}

// Initialize early — ideally in <head> before any content loads
const vitals = new WebVitalsCollector();

Where This Lives in Production

  • Google's web-vitals library — The official CWV measurement library is built entirely on PerformanceObserver. Powers Chrome UX Report data.
  • Vercel Analytics / Next.js — Uses PerformanceObserver to collect LCP, FID, CLS and send them via the Reporting API to Vercel's dashboard.
  • Sentry Performance Monitoring — Creates PerformanceObservers at SDK init to capture transaction spans from resource and navigation entries.
  • Cloudflare Web Analytics — Lightweight script that relies solely on PerformanceObserver (no polling) to keep its bundle under 1KB.

Common Mistakes

  • Forgetting buffered: true — Your analytics loads late. Without buffering, you miss all early entries (LCP, FCP, navigation).
  • Using entryTypes (plural) when you need buffering — Buffering only works with the single-type { type: '...' } syntax.
  • Not disconnecting observers — Resource observers on long-lived SPAs accumulate thousands of entries. Disconnect or limit scope.
  • Assuming synchronous delivery — Callbacks are queued as microtasks. Don't expect entries immediately after the event occurs.
  • Ignoring supportedEntryTypes — Not all browsers support all types. Check PerformanceObserver.supportedEntryTypes before observing.

🚀 Capstone: Production RAG System

You're the agency owner. A Fortune 500 client just hired you to build a zero-hallucination RAG system for 10 million documents. Build and deliver it end-to-end.

Advanced Production 10M Scale Full Code
📋 Client Brief

Client: Enterprise X (10,000 employees, multiple offices worldwide)

Request: "We have 10 million documents spread across PDFs, Word files, emails, Slack messages, web pages, databases, code repos, and scanned paper documents. Build us an AI system that can answer any question about our company's knowledge — with zero hallucination, full citations, and sub-3-second response time."

Your role: Agency owner. You design, build, and deploy the entire system. No shortcuts. Production-ready.

Configuration (src/config.py)

from pydantic_settings import BaseSettings
from pydantic import Field

class Settings(BaseSettings):
    """Application configuration loaded from environment variables."""
    
    # API Keys
    openai_api_key: str = Field(..., env="OPENAI_API_KEY")
    cohere_api_key: str = Field(..., env="COHERE_API_KEY")
    
    # Infrastructure
    qdrant_url: str = Field(default="http://localhost:6333")
    elasticsearch_url: str = Field(default="http://localhost:9200")
    redis_url: str = Field(default="redis://localhost:6379")
    jaeger_endpoint: str = Field(default="http://localhost:4317")
    
    # Embedding
    embedding_model: str = Field(default="BAAI/bge-m3")
    embedding_dimension: int = Field(default=1024)
    embedding_batch_size: int = Field(default=64)
    
    # Retrieval
    bm25_weight: float = Field(default=0.3)
    vector_weight: float = Field(default=0.7)
    retrieval_top_k: int = Field(default=50)
    rerank_top_k: int = Field(default=5)
    semantic_cache_threshold: float = Field(default=0.92)
    
    # Generation
    llm_model: str = Field(default="gpt-4o")
    llm_temperature: float = Field(default=0.0)
    max_output_tokens: int = Field(default=1024)
    
    # Safety
    min_confidence_threshold: float = Field(default=0.7)
    hallucination_threshold: float = Field(default=0.15)
    max_retry_attempts: int = Field(default=2)
    
    class Config:
        env_file = ".env"

settings = Settings()

Getting Started

# 1. Clone and enter the project
git clone https://github.com/your-org/enterprise-rag.git
cd enterprise-rag

# 2. Copy environment template and add your API keys
cp .env.example .env
# Edit .env with your OPENAI_API_KEY and COHERE_API_KEY

# 3. Start all infrastructure (one command!)
docker compose up -d

# 4. Verify services are running
curl http://localhost:6333/health    # Qdrant
curl http://localhost:9200/_cluster/health  # Elasticsearch
curl http://localhost:6379/ping      # Redis (via redis-cli)
open http://localhost:16686          # Jaeger UI

# 5. Install Python dependencies (for local dev)
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt

# 6. Ingest documents
python -m src.ingestion.pipeline --input ./data/documents/

# 7. Start the API
uvicorn src.api.app:app --host 0.0.0.0 --port 8000 --reload

# 8. Test a query
curl -X POST http://localhost:8000/query \
  -H "Content-Type: application/json" \
  -d '{"query": "What is the company vacation policy?"}'

RAG Course / Citation Responses

Stage 6: Citation-Backed Responses

Every major claim links back to exact chunks, documents, or timestamps. Full traceability — like a research paper with footnotes.

Intermediate Code Production
🏠 Daily-Life Analogy: Academic Paper References

When a scientist writes a paper saying "Coffee reduces heart disease risk by 12%," they don't just state it — they add a reference: [Smith et al., 2023, Journal of Medicine, p.45].

This lets anyone verify the claim by checking the original source. If the reference doesn't support the claim, the paper gets retracted.

Citation-backed responses work the same way. Every fact the AI states comes with a link to the exact document and passage that says so. Users can click and verify. If it's wrong, you can trace exactly where the error came from.

Why Citations Are Non-Negotiable

  • Trust: Users can verify claims by checking the source themselves
  • Accountability: If something is wrong, you know exactly which document caused the error
  • Debugging: Engineers can trace which retrieval step produced the cited chunk
  • Legal compliance: Many industries require traceability of AI-generated answers
  • Hallucination detection: A claim without a citation is immediately suspicious
💡 Key Insight

If the model can't cite a source for a claim, that claim is almost certainly hallucinated. Citations are both an output feature AND a hallucination detection mechanism.

Types of Citations

Citation Type What It Links To Example Best For
Document-level The entire source document [HR Policy v3.2] Simple answers from one doc
Chunk-level Specific chunk/paragraph [HR Policy v3.2, Section 4.1, Para 2] Precise claim verification
Quote-level Exact verbatim text from source "Employees receive 20 days..." [Source A] Maximum verifiability
Timestamped Document + version + date [HR Policy, v3.2, updated 2024-03-15] Time-sensitive information

How to Implement Citations

Step 1: Format Context with Source IDs

def format_context_with_citations(chunks: List[Dict]) -> str:
    """
    Format retrieved chunks with clear source identifiers
    that the LLM can reference in its answer.
    """
    formatted_sections = []
    
    for i, chunk in enumerate(chunks):
        source_id = f"[Source {i+1}]"
        metadata = chunk["metadata"]
        
        section = f"""--- {source_id} ---
Document: {metadata['title']}
Section: {metadata.get('section', 'N/A')}
Date: {metadata['updated_at']}
Confidence: {chunk.get('confidence', {}).get('overall', 'N/A')}
Content:
{chunk['content']}
---"""
        formatted_sections.append(section)
    
    return "\n\n".join(formatted_sections)

Step 2: Prompt for Inline Citations

CITATION_PROMPT = """Answer the question using the provided sources.

CITATION RULES:
1. Every factual claim MUST end with a citation: [Source N]
2. If a claim combines info from multiple sources: [Source 1, Source 3]
3. Direct quotes must be in quotation marks with citation
4. If you cannot cite a source for a claim, DO NOT include that claim
5. Use this format: "statement of fact [Source N]"

Example:
"Employees receive 20 vacation days per year [Source 1]. Remote workers 
get an additional 5 days [Source 2]. The policy was last updated in 
March 2024 [Source 1]."

Sources:
{formatted_context}

Question: {query}

Answer (with inline citations):"""

Step 3: Parse and Validate Citations

import re
from typing import List, Dict, Tuple

def parse_citations(answer: str, num_sources: int) -> Dict:
    """
    Parse citations from the generated answer and validate them.
    
    Returns:
        - Parsed citations with their claims
        - Uncited claims (potential hallucinations)
        - Invalid citations (referencing non-existent sources)
    """
    # Find all citations in [Source N] format
    citation_pattern = r'\[Source\s+(\d+(?:\s*,\s*\d+)*)\]'
    
    # Split answer into sentences
    sentences = re.split(r'(?<=[.!?])\s+', answer)
    
    cited_claims = []
    uncited_claims = []
    invalid_citations = []
    
    for sentence in sentences:
        sentence = sentence.strip()
        if not sentence:
            continue
        
        # Find citations in this sentence
        citations = re.findall(citation_pattern, sentence)
        
        if citations:
            # Extract source numbers
            source_nums = []
            for citation in citations:
                nums = [int(n.strip()) for n in citation.split(",")]
                source_nums.extend(nums)
            
            # Validate source numbers exist
            valid_nums = [n for n in source_nums if 1 <= n <= num_sources]
            invalid_nums = [n for n in source_nums if n < 1 or n > num_sources]
            
            if invalid_nums:
                invalid_citations.append({
                    "claim": sentence,
                    "invalid_sources": invalid_nums
                })
            
            cited_claims.append({
                "claim": re.sub(citation_pattern, "", sentence).strip(),
                "sources": valid_nums
            })
        else:
            # No citation found — potential hallucination
            if len(sentence.split()) > 5:  # Skip short connector phrases
                uncited_claims.append(sentence)
    
    return {
        "cited_claims": cited_claims,
        "uncited_claims": uncited_claims,
        "invalid_citations": invalid_citations,
        "citation_coverage": len(cited_claims) / 
            (len(cited_claims) + len(uncited_claims)) if 
            (cited_claims or uncited_claims) else 0
    }

Step 4: Verify Citation Accuracy

def verify_citation_accuracy(
    cited_claims: List[Dict],
    source_chunks: List[Dict]
) -> List[Dict]:
    """
    Verify that each citation actually supports its claim.
    
    A citation is accurate if the source chunk contains
    information that supports the claim being made.
    """
    verified_claims = []
    
    for claim_info in cited_claims:
        claim_text = claim_info["claim"]
        source_indices = claim_info["sources"]
        
        # Check if any cited source actually supports this claim
        supporting_sources = []
        for idx in source_indices:

                supporting_sources.append({
                    "source_idx": idx,
                    "support_score": support_score
                })
        
        verified_claims.append({
            "claim": claim_text,
            "cited_sources": source_indices,
            "verified_support": len(supporting_sources) > 0,
            "support_details": supporting_sources
        })
    
    return verified_claims

Complete Citation Pipeline

class CitationEngine:
    """
    End-to-end citation system.
    Generates cited answers and verifies every citation.
    """
    
    def __init__(self, llm, verifier):
        self.llm = llm
        self.verifier = verifier
    
    def generate_cited_answer(
        self,
        query: str,
        context_chunks: List[Dict]
    ) -> Dict:
        """Generate an answer with verified citations."""
        
        # 1. Format context with source IDs
        formatted = format_context_with_citations(context_chunks)
        
        # 2. Generate cited answer
        answer = self.llm.generate(
            CITATION_PROMPT.format(
                formatted_context=formatted, 
                query=query
            ),
            temperature=0.1
        )
        
        # 3. Parse citations from the answer
        parsed = parse_citations(answer, len(context_chunks))
        
        # 4. Verify citation accuracy
        verified = verify_citation_accuracy(
            parsed["cited_claims"], context_chunks
        )
        
        # 5. Flag any issues
        issues = []
        if parsed["uncited_claims"]:
            issues.append(f"{len(parsed['uncited_claims'])} uncited claims detected")
        
        unverified = [v for v in verified if not v["verified_support"]]
        if unverified:
            issues.append(f"{len(unverified)} citations don't match their source")
        
        return {
            "answer": answer,
            "citations": parsed,
            "verification": verified,
            "citation_coverage": parsed["citation_coverage"],
            "issues": issues,
            "quality_score": self._compute_quality(parsed, verified),
            "source_documents": [
                {
                    "id": c["chunk_id"],
                    "title": c["metadata"]["title"],
                    "url": c["metadata"].get("url", ""),
                    "date": c["metadata"]["updated_at"]
                }
                for c in context_chunks
            ]
        }
    
    def _compute_quality(self, parsed, verified) -> float:
        """Compute overall citation quality score 0-1."""
        coverage = parsed["citation_coverage"]
        accuracy = (
            sum(1 for v in verified if v["verified_support"]) / 
            len(verified) if verified else 0
        )
        return (coverage * 0.4) + (accuracy * 0.6)

🏢 What Production Systems Actually Do

  • Perplexity AI — Shows numbered citations inline with clickable source links
  • Google Gemini (with search) — Provides "View sources" with snippet previews
  • Enterprise RAG (Microsoft Copilot) — Links to SharePoint/Confluence pages with highlighted passages
  • Legal AI tools — Require paragraph-level citations with exact page/section numbers
  • Best practice: Show citation inline + expandable source panel with full context

📋 Summary

  • Every factual claim in the response MUST link to a specific source document/chunk
  • Citations serve dual purpose: user trust AND hallucination detection
  • Uncited claims are immediate red flags — likely hallucinations
  • Verify citations programmatically: does the cited source actually support the claim?
  • Include metadata in citations: document title, date, confidence, direct link
  • Citation quality score = (coverage × 0.4) + (accuracy × 0.6)

🧠 Mental Model

Answer: "The budget for Q3 is $2.5M [Source 1], allocated across 3 departments [Source 2]." Verification: ├── "budget for Q3 is $2.5M" → Check Source 1 → ✅ Source says "$2.5M for Q3" ├── "allocated across 3 departments" → Check Source 2 → ✅ Source lists 3 depts └── Citation quality: 100% coverage, 100% accuracy → PASS Red flag example: Answer: "The budget is $2.5M [Source 1] and will increase next year." ↑ NO CITATION = likely hallucinated

Think of it as: A lawyer who can't make a claim in court without pointing to evidence. No evidence = claim gets thrown out.

❌ Beginner Mistakes to Avoid

  • Document-level only citations: "Based on the HR Policy..." is too vague. Cite the specific section/paragraph.
  • Not verifying citations: Models sometimes cite the wrong source number. Always programmatically check.
  • Allowing uncited claims: If a claim has no citation, either add one or remove the claim entirely.
  • Citations without links: Users need to click through and verify. A citation without a way to check the source is useless.
  • Not showing confidence: Not all citations are equal. Show the confidence level of each source so users know which citations are rock-solid vs. uncertain.

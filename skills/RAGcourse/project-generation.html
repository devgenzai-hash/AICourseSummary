P5: Generation & Safety

Constrained generation with GPT-4o, citation extraction, NLI-based hallucination detection (DeBERTa-v3), confidence decisions, and a 5-level fallback engine.

Advanced Full Code Zero Hallucination

1. Constrained Generation System Prompt

The system prompt is the first line of defense against hallucination. Every constraint must be explicit.

# src/generation/prompts.py

SYSTEM_PROMPT = """You are an enterprise knowledge assistant. You answer questions
ONLY using the provided context documents. You MUST follow these rules:

RULES:
1. ONLY use information from the numbered context documents below.
2. CITE every claim with [1], [2], etc. matching the context number.
3. If the context does NOT contain enough information to answer, say:
   "I don't have sufficient information to answer this question."
4. NEVER invent facts, statistics, dates, or names not in the context.
5. If sources CONFLICT, state both positions with citations.
6. For numerical data, quote the EXACT numbers from the source.
7. Distinguish between facts and opinions when sources express opinions.

RESPONSE FORMAT:
- Start with a direct answer (1-2 sentences)
- Follow with detailed explanation citing sources
- End with confidence indicator: [HIGH/MEDIUM/LOW confidence]

CONTEXT DOCUMENTS:
{context}

USER QUESTION: {question}"""

CONTEXT_TEMPLATE = """[{index}] Source: {source_type} | {title}
Confidence: {confidence:.0%}
Content: {content}
---"""

2. Generation Engine (GPT-4o with Structured Output)

# src/generation/engine.py

from openai import OpenAI
from pydantic import BaseModel, Field
from typing import List, Optional
from enum import Enum
from src.config import settings
from .prompts import SYSTEM_PROMPT, CONTEXT_TEMPLATE

class ConfidenceLevel(Enum):
    HIGH = "high"
    MEDIUM = "medium"
    LOW = "low"
    INSUFFICIENT = "insufficient"

class Citation(BaseModel):
    """A citation linking a claim to a source document."""
    source_index: int          # Which context document [1], [2], etc.
    claim: str                 # The specific claim being cited
    quote: Optional[str] = None  # Exact quote from source (for verification)

class GeneratedResponse(BaseModel):
    """Structured output from the generation engine."""
    answer: str
    citations: List[Citation]
    confidence: ConfidenceLevel
    reasoning: str = ""       # Why this confidence level
    sources_used: List[int] = Field(default_factory=list)

class GenerationEngine:
    """
    Generate answers using GPT-4o with structured output.
    Forces the model to produce citations and confidence levels.
    """
    
    def __init__(self):
        self.client = OpenAI(api_key=settings.openai_api_key)
        self.model = settings.generation_model  # "gpt-4o"
    
    def generate(self, query: str, scored_chunks: List[dict]) -> GeneratedResponse:
        """
        Generate a response with citations.
        
        Args:
            query: User's question
            scored_chunks: Output from retrieval (chunks + confidence scores)
        """
        # Format context documents with numbers
        context = self._format_context(scored_chunks)
        
        # Build the prompt
        system = SYSTEM_PROMPT.format(context=context, question=query)
        
        # Call GPT-4o with structured output
        response = self.client.beta.chat.completions.parse(
            model=self.model,
            messages=[
                {"role": "system", "content": system},
                {"role": "user", "content": query}
            ],
            response_format=GeneratedResponse,
            temperature=0.1,  # Low temp for factual accuracy
            max_tokens=2000
        )
        
        return response.choices[0].message.parsed
    
    def _format_context(self, scored_chunks: List[dict]) -> str:
        """Format scored chunks into numbered context documents."""
        parts = []
        for i, item in enumerate(scored_chunks, 1):
            chunk = item["chunk"]
            confidence = item["confidence"]
            
            formatted = CONTEXT_TEMPLATE.format(
                index=i,
                source_type=chunk.source_type,
                title=chunk.metadata.get("title", "Unknown"),
                confidence=confidence.overall,
                content=chunk.content[:2000]  # Truncate very long chunks
            )
            parts.append(formatted)
        
        return "\n".join(parts)

3. Hallucination Detector (NLI with DeBERTa-v3)

⚠️ Why NLI for Hallucination Detection?

Natural Language Inference (NLI) determines if a claim is ENTAILED by, CONTRADICTS, or is NEUTRAL to a premise. We use each citation claim as hypothesis and the source text as premise. If NLI says "contradiction" or "neutral" → hallucination detected.

# src/generation/hallucination_detector.py

from transformers import pipeline
from typing import List, Tuple
from dataclasses import dataclass

@dataclass
class HallucinationResult:
    claim: str
    source_text: str
    verdict: str          # "entailment", "contradiction", "neutral"
    confidence: float
    is_hallucination: bool

class HallucinationDetector:
    """
    Detect hallucinations by verifying each citation against its source.
    
    Uses DeBERTa-v3-large-mnli:
    - SOTA on NLI benchmarks
    - Runs locally (no API cost)
    - ~50ms per claim (GPU) / ~200ms (CPU)
    """
    
    def __init__(self):
        self.nli = pipeline(
            "zero-shot-classification",
            model="microsoft/deberta-v3-large-mnli",
            device=0  # GPU
        )
        self.entailment_threshold = 0.7
    
    def verify_response(
        self,
        response,
        scored_chunks: List[dict]
    ) -> Tuple[bool, List[HallucinationResult]]:
        """
        Verify all citations in a response.
        
        Returns:
            (is_safe, results) — is_safe=True if no hallucinations detected
        """
        results = []
        
        for citation in response.citations:
            # Get the source text this citation references
            if citation.source_index > len(scored_chunks):
                # Citation references non-existent source!
                results.append(HallucinationResult(
                    claim=citation.claim,
                    source_text="",
                    verdict="contradiction",
                    confidence=1.0,
                    is_hallucination=True
                ))
                continue
            
            source = scored_chunks[citation.source_index - 1]
            source_text = source["chunk"].content
            
            # Run NLI: premise=source, hypothesis=claim
            result = self._check_entailment(source_text, citation.claim)
            results.append(result)
        
        # Response is safe if no hallucinations found
        is_safe = not any(r.is_hallucination for r in results)
        return is_safe, results
    
    def _check_entailment(self, premise: str, hypothesis: str) -> HallucinationResult:
        """
        Check if the premise (source text) entails the hypothesis (claim).
        """
        # Truncate premise to model max length
        premise_truncated = premise[:1500]
        
        result = self.nli(
            premise_truncated,
            candidate_labels=["entailment", "contradiction", "neutral"],
            hypothesis=hypothesis,
            multi_label=False
        )
        
        # Get scores for each label
        label_scores = dict(zip(result["labels"], result["scores"]))
        
        entailment_score = label_scores.get("entailment", 0)
        contradiction_score = label_scores.get("contradiction", 0)
        
        # Determine verdict
        if entailment_score >= self.entailment_threshold:
            verdict = "entailment"
            is_hallucination = False
        elif contradiction_score > 0.5:
            verdict = "contradiction"
            is_hallucination = True
        else:
            verdict = "neutral"
            # Neutral = claim might not be supported by source
            is_hallucination = entailment_score < 0.4
        
        return HallucinationResult(
            claim=hypothesis,
            source_text=premise_truncated[:200] + "...",
            verdict=verdict,
            confidence=max(entailment_score, contradiction_score),
            is_hallucination=is_hallucination
        )

4. Fallback Decision Engine

# src/generation/fallback.py

from enum import Enum
from dataclasses import dataclass
from typing import List

class ResponseDecision(Enum):
    """Five-level response decision."""
    ANSWER = "answer"         # Full confident answer
    CAVEAT = "caveat"         # Answer with uncertainty warning
    PARTIAL = "partial"       # Partial answer + what's missing
    REFUSE = "refuse"         # Cannot answer, explain why
    ESCALATE = "escalate"     # Hand off to human expert

@dataclass
class FallbackResult:
    decision: ResponseDecision
    response: str
    reasoning: str
    hallucinations_found: int = 0
    confidence_score: float = 0.0

class FallbackEngine:
    """
    Decides what to do based on:
    - Retrieval confidence (avg score from retrieval stage)
    - Hallucination check results
    - Generation confidence level
    
    Decision tree:
    ┌─ High confidence + No hallucinations → ANSWER
    ├─ Medium confidence + No hallucinations → CAVEAT
    ├─ Low confidence + Partial info → PARTIAL
    ├─ Hallucination detected → REFUSE (regenerate or refuse)
    └─ No relevant info / contradictions → ESCALATE
    """
    
    def decide(
        self,
        retrieval_result,
        generation_response,
        hallucination_results: List
    ) -> FallbackResult:
        
        hallucinations = [r for r in hallucination_results if r.is_hallucination]
        avg_confidence = retrieval_result.avg_confidence
        
        # Case 1: Hallucinations detected → REFUSE
        if len(hallucinations) > 0:
            return FallbackResult(
                decision=ResponseDecision.REFUSE,
                response=self._build_refuse_response(hallucinations),
                reasoning=f"Detected {len(hallucinations)} unsupported claims",
                hallucinations_found=len(hallucinations),
                confidence_score=avg_confidence
            )
        
        # Case 2: No evidence found → ESCALATE
        if not retrieval_result.has_sufficient_evidence:
            return FallbackResult(
                decision=ResponseDecision.ESCALATE,
                response="I don't have sufficient information in our knowledge base to answer this question. Let me connect you with a subject matter expert.",
                reasoning="Insufficient evidence in retrieval results",
                confidence_score=avg_confidence
            )
        
        # Case 3: High confidence → ANSWER
        if avg_confidence >= 0.75 and generation_response.confidence.value == "high":
            return FallbackResult(
                decision=ResponseDecision.ANSWER,
                response=generation_response.answer,
                reasoning="High confidence from both retrieval and generation",
                confidence_score=avg_confidence
            )
        
        # Case 4: Medium confidence → CAVEAT
        if avg_confidence >= 0.5:
            caveat = f"{generation_response.answer}\n\n⚠️ Note: This answer is based on sources with moderate confidence. Please verify critical details."
            return FallbackResult(
                decision=ResponseDecision.CAVEAT,
                response=caveat,
                reasoning="Moderate confidence — adding uncertainty caveat",
                confidence_score=avg_confidence
            )
        
        # Case 5: Low confidence → PARTIAL
        return FallbackResult(
            decision=ResponseDecision.PARTIAL,
            response=self._build_partial_response(generation_response),
            reasoning="Low confidence — providing partial answer with gaps",
            confidence_score=avg_confidence
        )
    
    def _build_refuse_response(self, hallucinations: List) -> str:
        """Build a refusal response explaining what went wrong."""
        return (
            "I cannot provide a reliable answer to this question. "
            "Some of the information I found could not be verified against "
            "the source documents. Please consult the original sources directly."
        )
    
    def _build_partial_response(self, response) -> str:
        """Build a partial response indicating gaps."""
        return (
            f"Based on limited information available:\n\n"
            f"{response.answer}\n\n"
            f"⚠️ This answer may be incomplete. The sources available had low "
            f"confidence scores and may not fully address your question."
        )

5. Response Formatter (Citations & Metadata)

# src/generation/formatter.py

from typing import List, Dict
from dataclasses import dataclass
from .fallback import FallbackResult, ResponseDecision

@dataclass
class FormattedResponse:
    """Final response ready for the API layer."""
    answer: str
    citations: List[Dict]
    confidence: float
    decision: str
    sources: List[Dict]
    trace_id: str = ""

class ResponseFormatter:
    """
    Format the final response with:
    - Clean answer text
    - Numbered citations with source links
    - Confidence indicator
    - Source metadata for transparency
    """
    
    def format(
        self,
        fallback_result: FallbackResult,
        generation_response,
        scored_chunks: List[dict],
        trace_id: str = ""
    ) -> FormattedResponse:
        
        # Build citation list
        citations = []
        if generation_response and hasattr(generation_response, 'citations'):
            for cit in generation_response.citations:
                if cit.source_index <= len(scored_chunks):
                    source = scored_chunks[cit.source_index - 1]
                    citations.append({
                        "index": cit.source_index,
                        "claim": cit.claim,
                        "source_title": source["chunk"].metadata.get("title", ""),
                        "source_type": source["chunk"].source_type,
                        "confidence": source["confidence"].overall
                    })
        
        # Build source list
        sources = []
        for i, item in enumerate(scored_chunks, 1):
            sources.append({
                "index": i,
                "title": item["chunk"].metadata.get("title", "Unknown"),
                "type": item["chunk"].source_type,
                "confidence": item["confidence"].overall,
                "path": item["chunk"].metadata.get("source", "")
            })
        
        return FormattedResponse(
            answer=fallback_result.response,
            citations=citations,
            confidence=fallback_result.confidence_score,
            decision=fallback_result.decision.value,
            sources=sources,
            trace_id=trace_id
        )

6. Complete RAG Generation Pipeline

# src/generation/rag_pipeline.py

from typing import Optional, List
import uuid
from src.retrieval.retriever import HybridRetriever
from .engine import GenerationEngine
from .hallucination_detector import HallucinationDetector
from .fallback import FallbackEngine, ResponseDecision
from .formatter import ResponseFormatter, FormattedResponse

class RAGPipeline:
    """
    End-to-end RAG pipeline: Query → Retrieve → Generate → Verify → Respond.
    
    This is the core orchestrator that chains all stages together.
    """
    
    def __init__(self):
        self.retriever = HybridRetriever()
        self.generator = GenerationEngine()
        self.hallucination_detector = HallucinationDetector()
        self.fallback = FallbackEngine()
        self.formatter = ResponseFormatter()
    
    def query(
        self,
        question: str,
        conversation: Optional[List] = None,
        source_filter: Optional[str] = None,
        max_retries: int = 1
    ) -> FormattedResponse:
        """
        Execute the full RAG pipeline.
        
        Flow:
        1. Retrieve relevant chunks (hybrid search + rerank)
        2. Generate answer with citations (GPT-4o structured output)
        3. Verify citations against sources (NLI hallucination check)
        4. Decide response level (ANSWER/CAVEAT/PARTIAL/REFUSE/ESCALATE)
        5. Format final response with sources
        
        Args:
            question: User's question
            conversation: Previous conversation turns
            source_filter: Optional filter (e.g., "pdf", "code")
            max_retries: Retries on hallucination detection
        """
        trace_id = str(uuid.uuid4())
        
        # ===== STAGE 1: RETRIEVE =====
        retrieval_result = self.retriever.retrieve(
            query=question,
            conversation=conversation,
            source_filter=source_filter
        )
        
        # Early exit: no evidence
        if not retrieval_result.has_sufficient_evidence:
            from .fallback import FallbackResult
            result = FallbackResult(
                decision=ResponseDecision.ESCALATE,
                response="I don't have sufficient information in our knowledge base to answer this. Let me connect you with an expert.",
                reasoning="No sufficient evidence",
                confidence_score=retrieval_result.avg_confidence
            )
            return self.formatter.format(result, None, [], trace_id)
        
        # ===== STAGE 2: GENERATE =====
        generation_response = self.generator.generate(
            query=question,
            scored_chunks=retrieval_result.chunks
        )
        
        # ===== STAGE 3: VERIFY (Hallucination Detection) =====
        is_safe, hallucination_results = self.hallucination_detector.verify_response(
            response=generation_response,
            scored_chunks=retrieval_result.chunks
        )
        
        # Retry once if hallucination detected
        if not is_safe and max_retries > 0:
            # Regenerate with stricter prompt
            generation_response = self.generator.generate(
                query=question + " (Be extra careful to only cite verified facts)",
                scored_chunks=retrieval_result.chunks
            )
            is_safe, hallucination_results = self.hallucination_detector.verify_response(
                response=generation_response,
                scored_chunks=retrieval_result.chunks
            )
        
        # ===== STAGE 4: DECIDE =====
        fallback_result = self.fallback.decide(
            retrieval_result=retrieval_result,
            generation_response=generation_response,
            hallucination_results=hallucination_results
        )
        
        # ===== STAGE 5: FORMAT =====
        return self.formatter.format(
            fallback_result=fallback_result,
            generation_response=generation_response,
            scored_chunks=retrieval_result.chunks,
            trace_id=trace_id
        )

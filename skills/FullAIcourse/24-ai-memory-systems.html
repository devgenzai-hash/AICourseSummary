AI Memory Systems

How does ChatGPT remember your name across conversations? How do AI agents recall past interactions? Memory systems — short-term, long-term, and episodic — make AI truly personal and useful.

🏠 Daily Life Analogy

Short-term memory = your notepad during a phone call. You write down what the person says right now. When the call ends, you tear off the sheet.

Long-term memory = your personal diary. Key facts and important events are stored permanently. You can look things up from months ago.

Episodic memory = photo albums. Full snapshots of past events. "Remember that trip to Paris?" — you recall the whole experience, not just facts.

Memory Types for AI

Memory TypeScopeStorageExample
Conversation (short-term)Current chat sessionMessage list"You said your name is Alex 3 messages ago"
Summary memoryCurrent session, compressedSummarized text"User is asking about Python deployment"
Long-term factsAcross all sessionsVector DB + structured"User prefers TypeScript, works at Acme Inc"
EpisodicPast conversationsVector DB"In March, we debugged a Redis issue together"
Semantic (RAG)External knowledgeVector DB"Company docs say the API rate limit is 100/min"

Production Memory System

# Complete AI memory system with multiple memory types
import json
import time
from datetime import datetime
from typing import Optional
from openai import OpenAI
import chromadb
from sentence_transformers import SentenceTransformer

class AIMemorySystem:
    """Multi-layer memory system for AI assistants."""
    
    def __init__(self, user_id: str):
        self.user_id = user_id
        self.llm = OpenAI(base_url="http://localhost:11434/v1", api_key="local")
        self.embedder = SentenceTransformer("all-MiniLM-L6-v2")
        
        # Short-term: current conversation
        self.conversation_history = []
        self.max_history = 20  # Keep last 20 messages
        
        # Long-term: persistent facts about the user
        self.chroma = chromadb.PersistentClient(path=f"./memory_{user_id}")
        self.facts_collection = self.chroma.get_or_create_collection("user_facts")
        self.episodes_collection = self.chroma.get_or_create_collection("episodes")
    
    def add_message(self, role: str, content: str):
        """Add message to conversation history."""
        self.conversation_history.append({
            "role": role,
            "content": content,
            "timestamp": datetime.now().isoformat()
        })
        
        # Trim if too long
        if len(self.conversation_history) > self.max_history:
            # Summarize old messages before removing them
            self._summarize_and_store()
            self.conversation_history = self.conversation_history[-10:]
    
    def extract_and_store_facts(self, message: str):
        """Extract facts from user messages and store long-term."""
        extraction_prompt = f"""Extract any personal facts from this user message.
Return JSON array of facts, or empty array if none found.
Examples of facts: name, job, preferences, tech stack, company, goals.

Message: "{message}"

Return ONLY a JSON array like: ["fact 1", "fact 2"] or []"""
        
        response = self.llm.chat.completions.create(
            model="llama3.1:8b",
            messages=[{"role": "user", "content": extraction_prompt}],
            temperature=0,
        )
        
        try:
            facts = json.loads(response.choices[0].message.content)
            for fact in facts:
                embedding = self.embedder.encode(fact).tolist()
                self.facts_collection.add(
                    ids=[f"fact_{int(time.time()*1000)}"],
                    embeddings=[embedding],
                    documents=[fact],
                    metadatas=[{"timestamp": datetime.now().isoformat()}]
                )
        except json.JSONDecodeError:
            pass  # Model didn't return valid JSON
    
    def recall_relevant_memories(self, query: str, top_k: int = 3) -> str:
        """Recall relevant long-term memories for current context."""
        memories = []
        
        # Search user facts
        if self.facts_collection.count() > 0:
            facts = self.facts_collection.query(
                query_texts=[query], n_results=min(top_k, self.facts_collection.count())
            )
            memories.extend(facts["documents"][0])
        
        # Search past episodes
        if self.episodes_collection.count() > 0:
            episodes = self.episodes_collection.query(
                query_texts=[query], n_results=min(2, self.episodes_collection.count())
            )
            memories.extend(episodes["documents"][0])
        
        if not memories:
            return ""
        
        return "Relevant memories:\n" + "\n".join([f"- {m}" for m in memories])
    
    def chat(self, user_message: str) -> str:
        """Full memory-augmented chat."""
        # Store the message
        self.add_message("user", user_message)
        
        # Extract facts (async in production)
        self.extract_and_store_facts(user_message)
        
        # Recall relevant memories
        memories = self.recall_relevant_memories(user_message)
        
        # Build context-rich prompt
        system = f"""You are a helpful AI assistant with memory.
You remember things about the user from past conversations.

{memories}

Use these memories naturally in conversation. Don't announce "I remember..."
unless directly relevant."""
        
        messages = [{"role": "system", "content": system}]
        messages.extend([{"role": m["role"], "content": m["content"]} for m in self.conversation_history])
        
        response = self.llm.chat.completions.create(
            model="llama3.1:8b",
            messages=messages,
            temperature=0.7,
        )
        
        assistant_msg = response.choices[0].message.content
        self.add_message("assistant", assistant_msg)
        return assistant_msg

# Usage
memory = AIMemorySystem(user_id="user_123")

# First conversation
print(memory.chat("Hi! I'm Alex, I work at Google as a Python developer."))
print(memory.chat("I'm building a RAG system for internal docs."))

# ... days later, new conversation ...
memory2 = AIMemorySystem(user_id="user_123")  # Same user, new session
print(memory2.chat("How should I handle authentication in my project?"))
# AI remembers: "user works at Google", "building RAG system"

Conversation Window Management

# Strategies for managing conversation history within context limits

class ConversationManager:
    """Manage conversation history within token limits."""
    
    def sliding_window(self, messages: list, max_messages: int = 20) -> list:
        """Keep only the last N messages (simplest)."""
        return messages[-max_messages:]
    
    def summarize_and_keep_recent(self, messages: list, llm) -> list:
        """Summarize old messages, keep recent ones verbatim."""
        if len(messages) <= 10:
            return messages
        
        # Summarize older messages
        old_messages = messages[:-10]
        recent_messages = messages[-10:]
        
        summary_prompt = "Summarize this conversation so far in 2-3 sentences:\n"
        summary_prompt += "\n".join([f"{m['role']}: {m['content']}" for m in old_messages])
        
        summary = llm.chat.completions.create(
            model="llama3.1:8b",
            messages=[{"role": "user", "content": summary_prompt}],
            max_tokens=150,
        ).choices[0].message.content
        
        # Return: summary + recent messages
        return [
            {"role": "system", "content": f"Previous conversation summary: {summary}"}
        ] + recent_messages
    
    def token_budget(self, messages: list, max_tokens: int = 3000) -> list:
        """Keep messages that fit within token budget (most accurate)."""
        result = []
        token_count = 0
        
        # Work backwards from most recent
        for msg in reversed(messages):
            msg_tokens = len(msg["content"]) // 4  # Rough estimate
            if token_count + msg_tokens > max_tokens:
                break
            result.insert(0, msg)
            token_count += msg_tokens
        
        return result

🏭 Industry Standards

  • ChatGPT uses all three memory types — Conversation window, summary compression, and persistent user memory.
  • mem0 (MemGPT) for production memory — Open-source library specifically for AI memory management.
  • Always ask before storing personal info — Privacy compliance (GDPR). Let users delete their memories.
  • Summarization for long conversations — Don't just truncate. Summarize old messages to preserve context.
  • Separate facts from episodes — "User likes Python" (fact) vs "We debugged Redis together on March 5" (episode).
  • Token budget management — Reserve tokens for: system prompt + memories + conversation + model response.

📝 Summary

  • Short-term memory = current conversation history (sliding window)
  • Long-term memory = extracted facts stored in vector DB (persistent)
  • Episodic memory = past conversation summaries (searchable)
  • Use LLM to extract facts from messages automatically
  • Use vector search to recall relevant memories for current context
  • Manage context window with summarization or token budgets

❌ Beginner Mistakes to Avoid

  • Sending entire conversation history every time — Exceeds context limit fast. Use sliding window + summarization.
  • Storing everything as memory — Not every message is worth remembering. Extract only key facts.
  • No memory expiry — Old facts become stale. "User uses Python 3.8" may be outdated. Add timestamps.
  • Ignoring privacy — Users must be able to view and delete stored memories. Required by law (GDPR).
  • Memory retrieval in the critical path — If vector search is slow, the whole response is delayed. Cache frequently accessed memories.

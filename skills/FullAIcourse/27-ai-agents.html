AI Agents

An AI agent is an LLM that can think, plan, use tools, and take actions autonomously. It's not just answering questions — it's completing multi-step tasks on its own, like a digital employee.

🏠 Daily Life Analogy

Regular chatbot = a librarian. You ask a question, they give an answer. That's it.

AI Agent = a personal assistant. You say "Book me a flight to Paris next Friday under $500." They research flights, compare prices, check your calendar, book the cheapest option, and confirm with you. Multiple steps, decisions, and actions — autonomously.

Agent vs Chatbot

FeatureChatbotAI Agent
InteractionSingle Q&AMulti-step task completion
Tool useNone or basicMultiple tools, chosen dynamically
PlanningNo planningBreaks tasks into steps
MemoryConversation onlyShort + long-term memory
AutonomyWaits for each messageActs independently between messages
Error recoveryNoneRetries, alternative approaches
Example"What's 2+2?" → "4""Analyze this CSV, make a chart, email it to my boss"

The ReAct Pattern (Reason + Act)

🧠 ReAct Loop

while task_not_complete:
    THINK  → "I need to find the user's order status"
    ACT    → call search_orders(user_id="123")
    OBSERVE → result: {"order": "shipped", "eta": "March 5"}
    THINK  → "Got the info, now I can respond"
    RESPOND → "Your order is shipped! Expected arrival: March 5"

Production AI Agent

# Complete AI Agent with ReAct pattern, tools, and planning
import json
from typing import Callable
from openai import OpenAI
from datetime import datetime

class AIAgent:
    """Production AI Agent with ReAct pattern."""
    
    def __init__(self, name: str, system_prompt: str, model: str = "llama3.1:8b"):
        self.name = name
        self.model = model
        self.client = OpenAI(base_url="http://localhost:11434/v1", api_key="local")
        self.system_prompt = system_prompt
        self.tools = {}
        self.tool_schemas = []
        self.conversation = []
        self.max_iterations = 10
        self.verbose = True
    
    def add_tool(self, name: str, func: Callable, description: str, parameters: dict):
        """Register a tool the agent can use."""
        self.tools[name] = func
        self.tool_schemas.append({
            "type": "function",
            "function": {
                "name": name,
                "description": description,
                "parameters": parameters,
            }
        })
    
    def _execute_tool(self, name: str, arguments: dict) -> str:
        """Execute a tool safely."""
        if name not in self.tools:
            return json.dumps({"error": f"Tool '{name}' not found"})
        try:
            result = self.tools[name](**arguments)
            return json.dumps(result, default=str)
        except Exception as e:
            return json.dumps({"error": str(e)})
    
    def run(self, task: str) -> str:
        """Execute a task using the ReAct loop."""
        self.conversation = [
            {"role": "system", "content": self.system_prompt},
            {"role": "user", "content": task},
        ]
        
        for iteration in range(self.max_iterations):
            if self.verbose:
                print(f"\n--- Iteration {iteration + 1} ---")
            
            # Ask the model what to do next
            response = self.client.chat.completions.create(
                model=self.model,
                messages=self.conversation,
                tools=self.tool_schemas if self.tool_schemas else None,
                tool_choice="auto" if self.tool_schemas else None,
            )
            
            msg = response.choices[0].message
            self.conversation.append(msg)
            
            # If no tool calls, the agent is done
            if not msg.tool_calls:
                if self.verbose:
                    print(f"✅ Agent finished: {msg.content[:100]}...")
                return msg.content
            
            # Execute each tool call
            for tool_call in msg.tool_calls:
                func_name = tool_call.function.name
                func_args = json.loads(tool_call.function.arguments)
                
                if self.verbose:
                    print(f"🔧 {func_name}({func_args})")
                
                result = self._execute_tool(func_name, func_args)
                
                if self.verbose:
                    print(f"📋 Result: {result[:200]}")
                
                self.conversation.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": result,
                })
        
        return "Agent reached maximum iterations without completing the task."

# ====== CREATE A RESEARCH AGENT ======

def web_search(query: str) -> dict:
    """Simulated web search."""
    return {"results": [
        {"title": f"Result about {query}", "snippet": f"Information about {query}..."},
    ]}

def read_file(path: str) -> dict:
    """Read a file from disk."""
    try:
        with open(path, "r") as f:
            return {"content": f.read()[:2000]}
    except FileNotFoundError:
        return {"error": f"File not found: {path}"}

def write_file(path: str, content: str) -> dict:
    """Write content to a file."""
    with open(path, "w") as f:
        f.write(content)
    return {"status": "written", "path": path, "bytes": len(content)}

def run_python(code: str) -> dict:
    """Execute Python code and return output."""
    import subprocess
    result = subprocess.run(
        ["python", "-c", code],
        capture_output=True, text=True, timeout=30
    )
    return {"stdout": result.stdout, "stderr": result.stderr, "returncode": result.returncode}

# Build the agent
agent = AIAgent(
    name="ResearchBot",
    system_prompt="""You are a research assistant agent. You can:
1. Search the web for information
2. Read and write files
3. Run Python code for analysis

When given a task:
- Break it down into steps
- Use tools to gather information
- Synthesize findings into a clear answer
- If a tool fails, try an alternative approach"""
)

# Register tools
agent.add_tool("web_search", web_search, "Search the web", {
    "type": "object",
    "properties": {"query": {"type": "string", "description": "Search query"}},
    "required": ["query"]
})
agent.add_tool("read_file", read_file, "Read a file", {
    "type": "object",
    "properties": {"path": {"type": "string", "description": "File path"}},
    "required": ["path"]
})
agent.add_tool("write_file", write_file, "Write to a file", {
    "type": "object",
    "properties": {
        "path": {"type": "string"},
        "content": {"type": "string"}
    },
    "required": ["path", "content"]
})
agent.add_tool("run_python", run_python, "Execute Python code", {
    "type": "object",
    "properties": {"code": {"type": "string", "description": "Python code to run"}},
    "required": ["code"]
})

# Run the agent!
result = agent.run("Research the top 3 Python web frameworks, compare their performance, and save a summary to frameworks.md")
print(result)

Multi-Agent Systems

# Multiple specialized agents working together

class MultiAgentSystem:
    """Orchestrate multiple specialized agents."""
    
    def __init__(self):
        self.agents = {}
        self.client = OpenAI(base_url="http://localhost:11434/v1", api_key="local")
    
    def add_agent(self, name: str, agent: AIAgent):
        self.agents[name] = agent
    
    def route_task(self, task: str) -> str:
        """Route a task to the most appropriate agent."""
        routing_prompt = f"""Given this task, which agent should handle it?
Available agents:
{chr(10).join([f'- {name}: {a.system_prompt[:100]}' for name, a in self.agents.items()])}

Task: {task}

Respond with ONLY the agent name."""
        
        response = self.client.chat.completions.create(
            model="llama3.1:8b",
            messages=[{"role": "user", "content": routing_prompt}],
            temperature=0,
        )
        
        agent_name = response.choices[0].message.content.strip()
        
        if agent_name in self.agents:
            print(f"📨 Routing to: {agent_name}")
            return self.agents[agent_name].run(task)
        else:
            # Fallback to first agent
            first_agent = list(self.agents.values())[0]
            return first_agent.run(task)

# Example: Specialized agents
coder = AIAgent(name="Coder", system_prompt="You write Python code. Focus on clean, working code.")
researcher = AIAgent(name="Researcher", system_prompt="You research topics and provide detailed summaries.")
reviewer = AIAgent(name="Reviewer", system_prompt="You review code for bugs, security issues, and improvements.")

system = MultiAgentSystem()
system.add_agent("coder", coder)
system.add_agent("researcher", researcher)
system.add_agent("reviewer", reviewer)

# Tasks get automatically routed
system.route_task("Write a function to parse CSV files")  # → Coder
system.route_task("What are the latest trends in AI?")    # → Researcher
system.route_task("Check this code for SQL injection")    # → Reviewer

Agent Planning Strategies

StrategyHow It WorksBest For
ReActThink → Act → Observe → RepeatGeneral tasks, simple workflows
Plan-then-ExecuteCreate full plan first, then execute stepsComplex multi-step tasks
Tree of ThoughtExplore multiple paths, pick bestProblems with multiple solutions
ReflectionAfter acting, check if result is correctTasks requiring accuracy
Human-in-the-LoopAsk human for approval at key stepsHigh-stakes actions

🏭 Industry Standards

  • LangChain/LangGraph — Most popular frameworks for building agents with complex workflows.
  • CrewAI — Multi-agent framework where agents have roles and collaborate.
  • AutoGen (Microsoft) — Multi-agent conversation framework for enterprise.
  • Always set max_iterations — Runaway agents can burn API credits fast. Typical limit: 5-15 steps.
  • Structured outputs for planning — Use JSON for plans so they're parseable and trackable.
  • Observability is critical — Log every thought, action, and result. Use LangSmith or custom logging.
  • Fallback strategies — If an agent gets stuck, have escape hatches (ask human, try different approach).

📝 Summary

  • AI Agent = LLM + Tools + Planning + Memory (autonomous task completion)
  • ReAct pattern: Think → Act → Observe → Repeat until done
  • Agents need: tool registry, iteration limits, error handling, logging
  • Multi-agent systems route tasks to specialized agents
  • Planning strategies: ReAct, Plan-then-Execute, Tree of Thought, Reflection
  • Production requires: observability, safety limits, human-in-the-loop for critical actions

❌ Beginner Mistakes to Avoid

  • No iteration limit — Agent loops forever, burns all your API credits. ALWAYS cap iterations.
  • Too many tools — More than 10-15 tools confuses the model. Group related tools or use routing.
  • No error recovery — When a tool fails, agent should try alternatives, not crash.
  • Autonomous dangerous actions — Agents that can delete data or send money without confirmation = disaster.
  • Not logging agent steps — When things go wrong, you can't debug without a trace of what happened.

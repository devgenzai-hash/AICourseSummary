Data Cleaning & Formatting

Your model is only as good as your data. This chapter covers the critical step between having raw data and being ready to train — cleaning, filtering, formatting, and validating your dataset.

🏠 Daily Life Analogy

Data cleaning = washing and prepping vegetables before cooking. You wouldn't throw muddy, bruised vegetables into a pot. You wash them, remove bad parts, chop them consistently, and THEN cook. Same with data — clean it before training.

Data formatting = following a recipe template. Every recipe has: Ingredients → Steps → Serving size. Similarly, every training example must follow the exact format your trainer expects.

Why Cleaning Matters

Dirty Data ProblemEffect on ModelSolution
Duplicate examplesModel memorizes instead of learningDeduplication (exact + fuzzy)
Very short responsesModel learns to give brief, unhelpful answersFilter by minimum length
Wrong formatTraining fails or produces garbageValidate JSON/format before training
Hallucinated factsModel learns to hallucinateFact-checking pipeline
Mixed languagesConfused multilingual behaviorLanguage detection + filtering
PII/sensitive dataModel memorizes private infoPII detection + removal
HTML/boilerplateModel learns to output HTML tagsStrip formatting artifacts

Chat Template Formats

Every model family expects data in a specific "chat template" format. Using the wrong format is the #1 reason fine-tuning fails silently.

ChatML (OpenAI / Most Models):

# This is the standard format used by most trainers
# TRL, Axolotl, OpenAI fine-tuning all use this
{
    "messages": [
        {"role": "system", "content": "You are a helpful coding assistant."},
        {"role": "user", "content": "How do I read a CSV file in Python?"},
        {"role": "assistant", "content": "Use pandas:\n```python\nimport pandas as pd\ndf = pd.read_csv('file.csv')\n```"}
    ]
}

# Multi-turn conversation (model learns context handling)
{
    "messages": [
        {"role": "system", "content": "You are a math tutor."},
        {"role": "user", "content": "What is 2+2?"},
        {"role": "assistant", "content": "2 + 2 = 4"},
        {"role": "user", "content": "Now multiply that by 3"},
        {"role": "assistant", "content": "4 × 3 = 12"}
    ]
}

Alpaca Format (Legacy but Common):

# Simpler, single-turn only
{
    "instruction": "Translate the following to French.",
    "input": "Hello, how are you?",
    "output": "Bonjour, comment allez-vous ?"
}

# Without input field
{
    "instruction": "Write a haiku about programming.",
    "input": "",
    "output": "Semicolons fall\nLike rain upon the keyboard\nCode compiles at last"
}

How Models Actually See the Data (After Template Applied):

# Llama 3 chat template (what the model actually processes)
"""<|begin_of_text|><|start_header_id|>system<|end_header_id|>

"""<|im_start|>system
You are a helpful assistant.<|im_end|>

Production Cleaning Pipeline

import json
import re
import hashlib
from typing import Optional
from datasets import Dataset, load_dataset

class DataCleaner:
    """Production data cleaning pipeline for LLM fine-tuning."""

    def __init__(self, min_instruction_len=10, min_response_len=50, max_response_len=8000):
        self.min_instruction_len = min_instruction_len
        self.min_response_len = min_response_len
        self.max_response_len = max_response_len
        self.seen_hashes = set()
        self.stats = {"total": 0, "kept": 0, "removed": {}}

    def clean_text(self, text: str) -> str:
        """Basic text cleaning."""
        # Remove excessive whitespace
        text = re.sub(r'\n{3,}', '\n\n', text)
        text = re.sub(r' {2,}', ' ', text)
        # Remove common artifacts
        text = re.sub(r'</?[a-z][^>]*>', '', text)  # HTML tags
        text = text.replace('\r\n', '\n')
        text = text.strip()
        return text

    def is_duplicate(self, text: str) -> bool:
        """Check for exact duplicates using hash."""
        h = hashlib.md5(text.lower().strip().encode()).hexdigest()
        if h in self.seen_hashes:
            return True
        self.seen_hashes.add(h)
        return False

    def check_quality(self, example: dict) -> Optional[str]:
        """Return rejection reason or None if passes."""
        messages = example.get("messages", [])

        if not messages:
            return "empty_messages"

        # Check for required roles
        roles = [m["role"] for m in messages]
        if "assistant" not in roles:
            return "no_assistant_response"
        if "user" not in roles:
            return "no_user_message"

        # Get the last assistant response
        assistant_msgs = [m["content"] for m in messages if m["role"] == "assistant"]
        user_msgs = [m["content"] for m in messages if m["role"] == "user"]

        # Length checks
        if any(len(m) < self.min_instruction_len for m in user_msgs):
            return "user_too_short"
        if any(len(m) < self.min_response_len for m in assistant_msgs):
            return "response_too_short"
        if any(len(m) > self.max_response_len for m in assistant_msgs):
            return "response_too_long"

        # Check for garbage patterns
        for msg in assistant_msgs:
            if "as an ai language model" in msg.lower():
                return "ai_refusal_pattern"
            if msg.count("I cannot") > 2:
                return "excessive_refusal"

        # Duplicate check
        full_text = " ".join(m["content"] for m in messages)
        if self.is_duplicate(full_text):
            return "duplicate"

        return None  # Passes all checks

    def clean_dataset(self, dataset) -> Dataset:
        """Clean an entire dataset."""
        cleaned = []

        for example in dataset:
            self.stats["total"] += 1

            # Clean text in all messages
            if "messages" in example:
                example["messages"] = [
                    {**m, "content": self.clean_text(m["content"])}
                    for m in example["messages"]
                ]

            # Quality check
            rejection = self.check_quality(example)
            if rejection:
                self.stats["removed"][rejection] = self.stats["removed"].get(rejection, 0) + 1
                continue

            cleaned.append(example)
            self.stats["kept"] += 1

        print(f"\n📊 Cleaning Results:")
        print(f"   Total: {self.stats['total']:,}")
        print(f"   Kept: {self.stats['kept']:,} ({self.stats['kept']/self.stats['total']*100:.1f}%)")
        print(f"   Removed: {self.stats['total'] - self.stats['kept']:,}")
        for reason, count in sorted(self.stats["removed"].items(), key=lambda x: -x[1]):
            print(f"     - {reason}: {count}")

        return Dataset.from_list(cleaned)

# Usage
cleaner = DataCleaner(min_response_len=100)
raw_dataset = load_dataset("your-dataset", split="train")
clean_dataset = cleaner.clean_dataset(raw_dataset)
clean_dataset.save_to_disk("./cleaned_dataset")

Format Converter: Alpaca → ChatML

def alpaca_to_chatml(example: dict, system_prompt: str = "You are a helpful assistant.") -> dict:
    """Convert Alpaca format to ChatML (messages) format."""
    messages = [{"role": "system", "content": system_prompt}]

    # Build user message
    user_content = example["instruction"]
    if example.get("input"):
        user_content += f"\n\nInput: {example['input']}"

    messages.append({"role": "user", "content": user_content})
    messages.append({"role": "assistant", "content": example["output"]})

    return {"messages": messages}

# Convert entire dataset
from datasets import load_dataset

alpaca = load_dataset("tatsu-lab/alpaca", split="train")
chatml_dataset = alpaca.map(alpaca_to_chatml)
print(chatml_dataset[0])

Token Count Verification

import tiktoken

def check_token_lengths(dataset, max_tokens=4096, model="gpt-4"):
    """Verify no examples exceed the context window."""
    enc = tiktoken.encoding_for_model(model)

    too_long = 0
    lengths = []

    for example in dataset:
        # Concatenate all message content
        full_text = " ".join(m["content"] for m in example["messages"])
        tokens = len(enc.encode(full_text))
        lengths.append(tokens)

        if tokens > max_tokens:
            too_long += 1

    print(f"Token length stats:")
    print(f"  Mean: {sum(lengths)/len(lengths):.0f}")
    print(f"  Max: {max(lengths)}")
    print(f"  Over {max_tokens} tokens: {too_long} ({too_long/len(lengths)*100:.1f}%)")

    # Filter out examples that are too long
    if too_long > 0:
        print(f"  ⚠️ Recommend truncating or removing {too_long} examples")

    return lengths

🏭 Industry Standards

  • ChatML format — The industry standard for SFT data. TRL, Axolotl, LLaMA-Factory all use it.
  • Always verify the chat template — Use tokenizer.apply_chat_template() to see exactly what the model will process.
  • Remove "As an AI language model..." — These patterns from GPT-3.5-generated data poison your model.
  • Balance your dataset — No more than 30% of examples should be from one topic/category.
  • Token budget — Keep examples under 2048 tokens for efficiency. Use 4096 only when needed.
  • Train/test split — Always hold out 5-10% for evaluation. Never train on your test set.
  • Version your data — Track dataset versions with metadata. A model is only reproducible if the data is.

📝 Summary

  • Data quality directly determines model quality — spend 80% of your time on data, 20% on training
  • ChatML format (messages with role/content) is the industry standard for SFT
  • Always: deduplicate, length filter, quality check, remove artifacts
  • Verify token counts don't exceed your training context window
  • Use tokenizer.apply_chat_template() to confirm correct formatting
  • Hold out a test split and version your datasets

🧠 Mental Model

Raw Data → Clean (remove junk) → Format (ChatML) → Validate (tokens, quality) → Split (train/test) → READY

Time spent: Data prep (80%) → Training (15%) → Evaluation (5%)

❌ Beginner Mistakes to Avoid

  • Wrong chat template — Using Alpaca format with a trainer that expects ChatML = silent failure. Model trains but outputs garbage.
  • Not checking token lengths — Examples exceeding context window get truncated, cutting off the response the model should learn.
  • Keeping "refuse" patterns — "I'm sorry, I cannot..." in training data teaches your model to refuse.
  • No test split — Without held-out data, you can't tell if training worked or if the model just memorized.
  • Inconsistent system prompts — Different system prompts across examples confuses the model about its identity.

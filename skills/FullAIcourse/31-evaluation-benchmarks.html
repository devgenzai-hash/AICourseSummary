Benchmarks & Evaluations

How do you know if your model is good? Benchmarks test standard skills, but custom evals test what actually matters for YOUR use case. Both are essential.

🏠 Daily Life Analogy

Benchmarks = standardized tests (SAT, GRE). Everyone takes the same test so you can compare scores across students.

Custom evals = job interview questions. Specific to YOUR role. A great SAT score doesn't mean they can do YOUR job well.

LLM-as-judge = asking a senior employee to grade the answers. Faster than grading yourself, but you need to calibrate their standards.

Building Custom Evaluations

# Custom evaluation framework for YOUR use case
import json
from typing import Callable
from openai import OpenAI
from dataclasses import dataclass

@dataclass
class EvalCase:
    """A single evaluation test case."""
    input: str
    expected: str  # Expected output or criteria
    category: str  # e.g., "accuracy", "safety", "format"

class LLMEvaluator:
    """Evaluate LLM outputs against test cases."""
    
    def __init__(self, model: str = "llama3.1:8b"):
        self.client = OpenAI(base_url="http://localhost:11434/v1", api_key="local")
        self.model = model
        self.results = []
    
    def run_eval(self, test_cases: list[EvalCase], system_prompt: str = "") -> dict:
        """Run evaluation across all test cases."""
        results = {"total": 0, "passed": 0, "failed": 0, "details": []}
        
        for case in test_cases:
            # Get model response
            messages = []
            if system_prompt:
                messages.append({"role": "system", "content": system_prompt})
            messages.append({"role": "user", "content": case.input})
            
            response = self.client.chat.completions.create(
                model=self.model, messages=messages, temperature=0
            )
            output = response.choices[0].message.content
            
            # Score the response
            passed = self._score(output, case.expected, case.category)
            
            results["total"] += 1
            results["passed" if passed else "failed"] += 1
            results["details"].append({
                "input": case.input,
                "expected": case.expected,
                "actual": output,
                "passed": passed,
                "category": case.category,
            })
        
        results["score"] = results["passed"] / results["total"] * 100
        return results
    
    def _score(self, output: str, expected: str, category: str) -> bool:
        """Score a single output against expected."""
        if category == "exact_match":
            return output.strip().lower() == expected.strip().lower()
        
        elif category == "contains":
            return expected.lower() in output.lower()
        
        elif category == "llm_judge":
            return self._llm_judge(output, expected)
        
        elif category == "json_valid":
            try:
                json.loads(output)
                return True
            except:
                return False
        
        return False
    
    def _llm_judge(self, output: str, criteria: str) -> bool:
        """Use another LLM to judge quality."""
        judge_prompt = f"""Judge if this AI response meets the criteria.

Criteria: {criteria}

Response to judge:
{output}

Does it meet the criteria? Answer ONLY "yes" or "no"."""
        
        judgment = self.client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": judge_prompt}],
            temperature=0,
        ).choices[0].message.content
        
        return "yes" in judgment.lower()

# ====== Define your test cases ======
test_cases = [
    EvalCase(
        input="What is the capital of France?",
        expected="paris",
        category="contains"
    ),
    EvalCase(
        input="Return a JSON object with keys: name, age",
        expected="",
        category="json_valid"
    ),
    EvalCase(
        input="Explain quantum computing to a 5-year-old",
        expected="Uses simple language, no jargon, relatable analogy",
        category="llm_judge"
    ),
    EvalCase(
        input="Write a haiku about Python programming",
        expected="Has exactly 3 lines with 5-7-5 syllable pattern",
        category="llm_judge"
    ),
]

# Run evaluation
evaluator = LLMEvaluator(model="llama3.1:8b")
results = evaluator.run_eval(test_cases)
print(f"Score: {results['score']:.1f}% ({results['passed']}/{results['total']} passed)")
for d in results["details"]:
    status = "✅" if d["passed"] else "❌"
    print(f"  {status} {d['input'][:50]}")

Comparing Models

# Compare multiple models on the same eval set

def compare_models(models: list[str], test_cases: list[EvalCase]) -> dict:
    """Run the same eval across multiple models."""
    comparison = {}
    
    for model in models:
        evaluator = LLMEvaluator(model=model)
        results = evaluator.run_eval(test_cases)
        comparison[model] = {
            "score": results["score"],
            "passed": results["passed"],
            "total": results["total"],
        }
        print(f"{model}: {results['score']:.1f}%")
    
    return comparison

# Example: Compare models
models_to_test = ["llama3.1:8b", "mistral:7b", "qwen2.5:7b"]
comparison = compare_models(models_to_test, test_cases)

# Output:
# llama3.1:8b: 85.0%
# mistral:7b: 75.0%
# qwen2.5:7b: 90.0%

🏭 Industry Standards

  • Custom evals > benchmarks — MMLU score doesn't tell you if the model works for YOUR specific task.
  • LLM-as-judge is standard — Use GPT-4 to judge quality at scale. Cheaper than human review.
  • Eval before and after fine-tuning — Must prove your fine-tuned model is actually better.
  • Test for regressions — When you improve one thing, check you didn't break another.
  • Frameworks: lm-evaluation-harness, deepeval, promptfoo — Don't build from scratch for standard benchmarks.
  • Human eval for final judgment — LLM judges are good for screening, humans for final quality bar.
  • Track evals over time — Keep a leaderboard of model versions and their scores.

📝 Summary

  • Standard benchmarks (MMLU, HumanEval, GSM8K) = compare across models
  • Custom evals = test what matters for YOUR specific use case
  • Scoring methods: exact match, contains, JSON valid, LLM-as-judge
  • LLM-as-judge = use a strong model to evaluate a weaker one
  • Always eval before AND after fine-tuning to prove improvement
  • Track scores over time, test for regressions

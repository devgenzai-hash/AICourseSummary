AI Orchestration

Complex AI systems don't use one model call. They chain multiple models, route between providers, handle fallbacks, and manage state across steps. This is orchestration — the conductor of your AI orchestra.

🏠 Daily Life Analogy

AI orchestration = a film director. The director doesn't act, film, or edit — they coordinate actors (models), camera crews (tools), and editors (post-processing) to create the final movie. Each specialist does their part, the director ensures it all comes together.

Orchestration Patterns

PatternHow It WorksWhen To Use
Sequential chainStep 1 → Step 2 → Step 3Multi-step processing (analyze → plan → write)
Parallel fan-outSend to N models, combine resultsComparing models, gathering perspectives
RouterClassify input, route to specialistDifferent models for different tasks
Fallback cascadeTry Model A, if fails try Model BReliability, cost optimization
Map-reduceSplit data → process each → combineLarge document processing
Evaluator loopGenerate → evaluate → regenerate if badQuality-critical outputs

Production Orchestrator

# AI Orchestration framework — chain, route, and manage multiple AI calls
import json
import asyncio
from typing import Callable, Any
from dataclasses import dataclass, field
from openai import OpenAI

@dataclass
class StepResult:
    step_name: str
    output: Any
    model_used: str
    tokens: int = 0
    latency_ms: float = 0

class AIOrchestrator:
    """Chain multiple AI operations with routing, fallbacks, and state."""
    
    def __init__(self):
        self.providers = {
            "local": OpenAI(base_url="http://localhost:11434/v1", api_key="local"),
            # "openai": OpenAI(api_key="sk-..."),
            # "anthropic": OpenAI(base_url="https://api.anthropic.com/v1", api_key="..."),
        }
        self.steps = []
        self.results = []
        self.state = {}  # Shared state between steps
    
    def add_step(self, name: str, func: Callable, **kwargs):
        """Add a step to the orchestration pipeline."""
        self.steps.append({"name": name, "func": func, "kwargs": kwargs})
        return self  # Enable chaining
    
    def run(self, initial_input: str) -> list[StepResult]:
        """Execute all steps sequentially, passing state between them."""
        self.state["input"] = initial_input
        self.results = []
        
        for step in self.steps:
            print(f"🔄 Running: {step['name']}")
            result = step["func"](self.state, **step["kwargs"])
            self.state[step["name"]] = result.output
            self.results.append(result)
            print(f"  ✅ Done ({result.tokens} tokens, {result.latency_ms:.0f}ms)")
        
        return self.results

# ====== Orchestration steps ======

import time

def classify_intent(state: dict, **kwargs) -> StepResult:
    """Step 1: Classify the user's intent."""
    client = OpenAI(base_url="http://localhost:11434/v1", api_key="local")
    start = time.time()
    
    response = client.chat.completions.create(
        model="llama3.1:8b",
        messages=[{"role": "user", "content": f"""Classify this request into one category:
- code_generation
- explanation
- debugging
- data_analysis
- creative_writing

Request: {state['input']}
Category:"""}],
        temperature=0, max_tokens=20,
    )
    
    return StepResult(
        step_name="classify_intent",
        output=response.choices[0].message.content.strip(),
        model_used="llama3.1:8b",
        tokens=response.usage.total_tokens,
        latency_ms=(time.time() - start) * 1000,
    )

def route_to_specialist(state: dict, **kwargs) -> StepResult:
    """Step 2: Route to specialized model/prompt based on intent."""
    client = OpenAI(base_url="http://localhost:11434/v1", api_key="local")
    intent = state.get("classify_intent", "explanation")
    start = time.time()
    
    # Different system prompts per intent
    prompts = {
        "code_generation": "You are an expert programmer. Write clean, production-ready code.",
        "explanation": "You explain complex topics simply. Use analogies.",
        "debugging": "You are a debugging expert. Find and fix the bug step by step.",
        "data_analysis": "You analyze data and provide clear insights with numbers.",
        "creative_writing": "You are a creative writer. Be vivid and engaging.",
    }
    
    system = prompts.get(intent, prompts["explanation"])
    
    response = client.chat.completions.create(
        model="llama3.1:8b",
        messages=[
            {"role": "system", "content": system},
            {"role": "user", "content": state["input"]},
        ],
        temperature=0.7,
    )
    
    return StepResult(
        step_name="route_to_specialist",
        output=response.choices[0].message.content,
        model_used="llama3.1:8b",
        tokens=response.usage.total_tokens,
        latency_ms=(time.time() - start) * 1000,
    )

def quality_check(state: dict, **kwargs) -> StepResult:
    """Step 3: Check output quality, regenerate if needed."""
    client = OpenAI(base_url="http://localhost:11434/v1", api_key="local")
    start = time.time()
    
    response = client.chat.completions.create(
        model="llama3.1:8b",
        messages=[{"role": "user", "content": f"""Rate this response quality 1-10:
Request: {state['input']}
Response: {state['route_to_specialist']}

Score (number only):"""}],
        temperature=0, max_tokens=5,
    )
    
    return StepResult(
        step_name="quality_check",
        output=response.choices[0].message.content.strip(),
        model_used="llama3.1:8b",
        tokens=response.usage.total_tokens,
        latency_ms=(time.time() - start) * 1000,
    )

# ====== Build and run the pipeline ======
orchestrator = AIOrchestrator()
orchestrator.add_step("classify_intent", classify_intent)
orchestrator.add_step("route_to_specialist", route_to_specialist)
orchestrator.add_step("quality_check", quality_check)

results = orchestrator.run("Write a Python function to merge two sorted lists")

# Print final results
print(f"\nIntent: {results[0].output}")
print(f"Response: {results[1].output[:200]}...")
print(f"Quality: {results[2].output}/10")
print(f"Total tokens: {sum(r.tokens for r in results)}")

Fallback & Multi-Provider

# Robust multi-provider system with fallbacks

class ModelRouter:
    """Route requests to models with fallback chains."""
    
    def __init__(self):
        self.providers = [
            {"name": "local", "client": OpenAI(base_url="http://localhost:11434/v1", api_key="local"), "model": "llama3.1:8b"},
            # {"name": "openai", "client": OpenAI(), "model": "gpt-4o-mini"},
            # {"name": "anthropic", "client": ..., "model": "claude-3-haiku"},
        ]
    
    def call_with_fallback(self, messages: list, **kwargs) -> dict:
        """Try each provider until one succeeds."""
        for provider in self.providers:
            try:
                response = provider["client"].chat.completions.create(
                    model=provider["model"],
                    messages=messages,
                    timeout=30,
                    **kwargs,
                )
                return {
                    "content": response.choices[0].message.content,
                    "provider": provider["name"],
                    "model": provider["model"],
                }
            except Exception as e:
                print(f"⚠️ {provider['name']} failed: {e}, trying next...")
                continue
        
        raise Exception("All providers failed")

router = ModelRouter()
result = router.call_with_fallback([{"role": "user", "content": "Hello!"}])
print(f"Response from {result['provider']}: {result['content']}")

🏭 Industry Standards

  • LangChain/LangGraph — Most popular orchestration framework. Chains, agents, state graphs.
  • Always have fallbacks — If OpenAI is down, switch to Anthropic. If that fails, use local model.
  • Use cheap models for routing — Classify with 8B model, generate with 70B. Save 80% on tokens.
  • Observability is critical — LangSmith, Langfuse, or custom logging. See every step and its result.
  • Structured state management — Pass state between steps explicitly. Makes debugging possible.
  • Timeout every LLM call — Models can hang. Always set timeouts (15-60 seconds).
  • Retry with exponential backoff — Rate limits are common. Retry 3 times with increasing delays.

📝 Summary

  • Orchestration = coordinating multiple AI calls into a coherent pipeline
  • Patterns: sequential chain, parallel fan-out, router, fallback cascade, map-reduce
  • Use cheap models for routing, expensive models for generation
  • Fallback chains: Local → OpenAI → Anthropic ensures uptime
  • Quality check loops: generate → evaluate → regenerate if score is low
  • Always: timeout, retry, log every step, track total tokens/cost

Building Chatbots & Copilots

From simple FAQ bots to full AI copilots that understand your codebase — learn how to build production chat interfaces that users actually love.

🏠 Daily Life Analogy

Chatbot = a receptionist. Answers common questions, routes complex ones to the right person, available 24/7.

Copilot = a pair programmer sitting next to you. Sees what you're working on, suggests code, explains errors, helps you think — but YOU make the final decisions.

Chatbot vs Copilot

FeatureChatbotCopilot
ContextUser's messages onlyUser's messages + workspace/app context
DomainGeneral or narrow FAQDeeply integrated with one tool
ActionsResponds with textCan edit code, run commands, create files
ExampleCustomer support botGitHub Copilot, Cursor AI
ComplexityLow-mediumHigh (needs deep integration)

Production Chatbot with Gradio

# Full chatbot with memory, RAG, and streaming
# pip install gradio openai chromadb

import gradio as gr
from openai import OpenAI

client = OpenAI(base_url="http://localhost:11434/v1", api_key="local")

SYSTEM_PROMPT = """You are a helpful customer support assistant for TechCo.

## Your Knowledge
- Products: Widget Pro ($49), Widget Basic ($19), Widget Enterprise (custom pricing)
- Shipping: Free over $50, otherwise $5.99. Ships in 2-5 business days.
- Returns: 30-day money-back guarantee, no questions asked.
- Support hours: 24/7 via chat, phone 9am-5pm EST.

## Rules
- Be friendly but concise (max 3 sentences per response)
- If you don't know something, say "Let me connect you with a human agent"
- Never make up information about products or pricing
- For billing issues, always suggest contacting billing@techco.com"""

def chat(message: str, history: list) -> str:
    """Chat function for Gradio interface."""
    messages = [{"role": "system", "content": SYSTEM_PROMPT}]
    
    # Add conversation history
    for user_msg, bot_msg in history:
        messages.append({"role": "user", "content": user_msg})
        messages.append({"role": "assistant", "content": bot_msg})
    
    messages.append({"role": "user", "content": message})
    
    response = client.chat.completions.create(
        model="llama3.1:8b",
        messages=messages,
        temperature=0.3,
        max_tokens=300,
    )
    
    return response.choices[0].message.content

# Streaming version
def chat_stream(message: str, history: list):
    """Streaming chat for better UX."""
    messages = [{"role": "system", "content": SYSTEM_PROMPT}]
    for user_msg, bot_msg in history:
        messages.append({"role": "user", "content": user_msg})
        messages.append({"role": "assistant", "content": bot_msg})
    messages.append({"role": "user", "content": message})
    
    stream = client.chat.completions.create(
        model="llama3.1:8b",
        messages=messages,
        temperature=0.3,
        stream=True,
    )
    
    partial = ""
    for chunk in stream:
        if chunk.choices[0].delta.content:
            partial += chunk.choices[0].delta.content
            yield partial

# Launch!
demo = gr.ChatInterface(
    fn=chat_stream,
    title="TechCo Support Bot",
    description="Ask about products, shipping, returns, or anything else!",
    examples=["What products do you offer?", "How long does shipping take?", "I want a refund"],
    theme="soft",
)
demo.launch(share=True)  # share=True creates a public URL

RAG-Enhanced Chatbot

# Chatbot that answers from your documents
import chromadb
from sentence_transformers import SentenceTransformer

class RAGChatbot:
    """Chatbot that answers using your company documents."""
    
    def __init__(self, docs_path: str):
        self.client = OpenAI(base_url="http://localhost:11434/v1", api_key="local")
        self.embedder = SentenceTransformer("all-MiniLM-L6-v2")
        self.chroma = chromadb.PersistentClient(path="./chatbot_db")
        self.collection = self.chroma.get_or_create_collection("docs")
        
        # Index documents on first run
        if self.collection.count() == 0:
            self._index_docs(docs_path)
    
    def _index_docs(self, path: str):
        """Index all documents for RAG."""
        import os
        for filename in os.listdir(path):
            if filename.endswith((".txt", ".md")):
                with open(os.path.join(path, filename)) as f:
                    text = f.read()
                # Chunk into paragraphs
                chunks = [c.strip() for c in text.split("\n\n") if c.strip()]
                for i, chunk in enumerate(chunks):
                    self.collection.add(
                        ids=[f"{filename}_{i}"],
                        documents=[chunk],
                        metadatas=[{"source": filename}]
                    )
    
    def chat(self, message: str, history: list = None) -> str:
        """Answer using RAG + conversation history."""
        # Retrieve relevant documents
        results = self.collection.query(query_texts=[message], n_results=3)
        context = "\n\n".join(results["documents"][0])
        
        system = f"""You are a helpful assistant. Answer based on the provided context.
If the answer isn't in the context, say "I don't have information about that."

Context from documents:
{context}"""
        
        messages = [{"role": "system", "content": system}]
        if history:
            for user_msg, bot_msg in history[-5:]:  # Last 5 turns
                messages.append({"role": "user", "content": user_msg})
                messages.append({"role": "assistant", "content": bot_msg})
        messages.append({"role": "user", "content": message})
        
        response = self.client.chat.completions.create(
            model="llama3.1:8b",
            messages=messages,
            temperature=0.3,
        )
        return response.choices[0].message.content

🏭 Industry Standards

  • Always stream responses — Users hate waiting 5 seconds for a blank response. Stream token-by-token.
  • Gradio for prototypes, custom UI for production — Gradio is fast to build. For production, use React + WebSocket.
  • RAG for domain-specific bots — Don't fine-tune for facts. Use RAG to ground responses in your docs.
  • Fallback to human — When confidence is low, route to a human agent. Never leave users stuck.
  • Track conversations — Log all interactions for quality analysis and improvement.
  • Safety guardrails — Filter harmful content, prevent prompt injection, block off-topic abuse.

📝 Summary

  • Chatbot: text-in/text-out assistant. Copilot: deeply integrated into a tool/workflow.
  • Use Gradio for quick prototypes, custom frontend for production.
  • Streaming is mandatory for good chat UX.
  • Add RAG for domain-specific knowledge (docs, FAQs, policies).
  • Include conversation history for multi-turn context.
  • Always have a fallback to human for complex/sensitive issues.

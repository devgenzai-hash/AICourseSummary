Open-Source vs Closed-Source Models

Should you use GPT-4 (closed API) or Llama (open weights you can run yourself)? This chapter breaks down the ecosystem, licensing, costs, and helps you decide for your project.

🏠 Daily Life Analogy

Open-source = owning a car. You own it, you can modify the engine, paint it, drive anywhere, no per-mile fee. But you handle maintenance, fuel, and repairs.

Closed-source = using Uber/taxi. Very convenient, no maintenance worries, pay per ride. But you can't modify the car, the company controls pricing, and they know where you go.

⚠️ Always Check the License

Before using any open model commercially, verify its license. "Open weights" ≠ "open source". Some models let you download weights but restrict commercial use (e.g., some research models on HuggingFace).

When to Use Which?

Use Closed-Source APIs When:

  • You're prototyping or building an MVP quickly
  • You need the absolute best quality and cost isn't a constraint
  • You don't have ML engineering expertise
  • Your volume is low (<100K requests/day)
  • You need multimodal capabilities (vision, audio)

Use Open-Source Models When:

  • Data privacy is critical (healthcare, finance, legal)
  • You need to fine-tune for a specific domain
  • Your volume is high (millions of requests/day — cheaper at scale)
  • You need full control over model behavior
  • You're operating in regulated industries (GDPR, HIPAA)
  • You want to avoid vendor lock-in

Production Code: Using Both

Multi-Provider Setup (Industry Pattern)

# Production pattern: Abstract the provider so you can switch easily
from openai import OpenAI
import os

class LLMClient:
    """Unified interface for multiple LLM providers."""

    def __init__(self, provider="openai"):
        self.provider = provider

        if provider == "openai":
            self.client = OpenAI()
            self.model = "gpt-4o-mini"
        elif provider == "anthropic":
            import anthropic
            self.client = anthropic.Anthropic()
            self.model = "claude-3-5-sonnet-20241022"
        elif provider == "ollama":
            # Ollama exposes an OpenAI-compatible API!
            self.client = OpenAI(
                base_url="http://localhost:11434/v1",
                api_key="ollama"  # dummy key, Ollama doesn't need auth
            )
            self.model = "llama3.1:8b"
        elif provider == "vllm":
            # vLLM also exposes OpenAI-compatible API
            self.client = OpenAI(
                base_url="http://localhost:8000/v1",
                api_key="token"
            )
            self.model = "meta-llama/Llama-3.1-8B-Instruct"

    def chat(self, message: str, system: str = "You are a helpful assistant.") -> str:
        """Send a message and get a response."""
        if self.provider == "anthropic":
            response = self.client.messages.create(
                model=self.model,
                max_tokens=1024,
                system=system,
                messages=[{"role": "user", "content": message}]
            )
            return response.content[0].text
        else:
            # OpenAI, Ollama, vLLM all use same API format
            response = self.client.chat.completions.create(
                model=self.model,
                messages=[
                    {"role": "system", "content": system},
                    {"role": "user", "content": message}
                ],
                temperature=0.7,
                max_tokens=1024
            )
            return response.choices[0].message.content

# Usage — switch providers with one line!
llm = LLMClient(provider="ollama")  # Free, private, local
# llm = LLMClient(provider="openai")  # Best quality, costs money
# llm = LLMClient(provider="vllm")    # Self-hosted, production-grade

answer = llm.chat("What is the capital of France?")
print(answer)

Cost Comparison Calculator

# Calculate when open-source becomes cheaper than APIs

def calculate_monthly_cost(
    requests_per_day: int,
    avg_input_tokens: int = 500,
    avg_output_tokens: int = 200
):
    """Compare monthly costs: API vs self-hosted."""
    monthly_requests = requests_per_day * 30
    total_input_tokens = monthly_requests * avg_input_tokens
    total_output_tokens = monthly_requests * avg_output_tokens

    # API costs (per million tokens)
    api_costs = {
        "GPT-4o": {"input": 2.50, "output": 10.00},
        "GPT-4o-mini": {"input": 0.15, "output": 0.60},
        "Claude 3.5 Sonnet": {"input": 3.00, "output": 15.00},
    }

    # Self-hosted costs (monthly GPU rental)
    self_hosted = {
        "Ollama on laptop": 0,        # Free (your hardware)
        "RunPod A100 80GB": 2200,   # ~$3/hr × 24 × 30
        "Lambda 8xA100": 12000,     # For 70B model
    }

    print(f"\n📊 Monthly cost comparison ({requests_per_day:,} requests/day):\n")
    print("API Providers:")
    for name, prices in api_costs.items():
        cost = (total_input_tokens * prices["input"] + total_output_tokens * prices["output"]) / 1_000_000
        print(f"  {name:25s}: ${cost:,.0f}/month")

    print("\nSelf-Hosted (unlimited requests):")
    for name, cost in self_hosted.items():
        print(f"  {name:25s}: ${cost:,.0f}/month")

# Try different scales
calculate_monthly_cost(requests_per_day=100)    # Small startup
calculate_monthly_cost(requests_per_day=10000)  # Growing product
calculate_monthly_cost(requests_per_day=100000) # Scale — self-hosted wins!

🏭 Industry Standards

  • Startups (MVP phase) — Almost always start with OpenAI/Anthropic API. Speed to market > cost.
  • Startups (growth phase) — Switch critical paths to open models, keep API for edge cases.
  • Enterprise — Open models for privacy-sensitive data. API for non-sensitive tasks.
  • Hybrid approach dominates — Most production systems use BOTH: fast/cheap API for simple tasks + custom model for core product.
  • OpenAI-compatible API — vLLM, Ollama, TGI all expose the same API format. Write once, deploy anywhere.
  • Model router pattern — Route easy queries to small/cheap models, hard queries to powerful/expensive ones.

Decision Framework

✅ Quick Decision Guide
  • Need it working in 1 hour? → API (OpenAI/Anthropic)
  • Sensitive data (medical/legal)? → Open model, self-hosted
  • Custom behavior needed? → Open model + fine-tuning
  • >50K requests/day? → Probably cheaper to self-host
  • Need absolute best quality? → GPT-4o / Claude Opus (for now)
  • Building a product, not just a demo? → Plan for open model migration

📝 Summary

  • Closed-source (GPT-4, Claude) = Convenient, best quality, pay-per-use, data leaves your control
  • Open-source (Llama, Mistral, Qwen) = Full control, privacy, can fine-tune, requires infrastructure
  • Open models are rapidly catching up to closed ones in quality
  • Most production apps use a hybrid approach
  • The OpenAI-compatible API standard lets you switch between providers easily
  • Always check the license before commercial use

🧠 Mental Model

Low volume + No privacy concerns → API (pay per token)
High volume OR Privacy needed → Self-host open model (pay for GPU)

Crossover point: ~$2,000-5,000/month in API costs = time to self-host

❌ Beginner Mistakes to Avoid

  • Starting with self-hosting when you should use an API — Don't over-engineer early. Validate your idea first with an API.
  • Ignoring the total cost of self-hosting — It's not just GPU cost. Add: engineering time, monitoring, scaling, failure handling.
  • Thinking open = free — Open models are free to download, but running them costs compute.
  • Tight coupling to one provider — Always abstract your LLM calls behind a common interface.
  • Not reading the license — "Open weights" ≠ free commercial use. Llama has a 700M user threshold.

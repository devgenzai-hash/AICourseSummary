Transformers & The Attention Mechanism

The Transformer is THE architecture behind every modern AI model — GPT, Llama, Claude, Gemini, all of them. The secret sauce? The "attention mechanism" that lets models focus on what matters.

🏠 Daily Life Analogy

Attention = highlighting a textbook while studying.

When you read a textbook and need to answer a question, you don't re-read the entire book equally. You scan, find the relevant paragraphs, and focus on those. That's exactly what attention does — for each word it generates, it "highlights" the most relevant previous words and pays more attention to them.

Transformer = a team of expert speed-readers who can all read different parts of the text simultaneously (in parallel), then share notes with each other. This is why Transformers are so much faster than older approaches that had to read text one-word-at-a-time.

Before Transformers: The Problem

Before 2017, AI used RNNs (Recurrent Neural Networks) and LSTMs to process text. These had two major problems:

ProblemWhat It MeansDaily Life Analogy
Sequential processing Must read one word at a time, in order Like reading a book letter-by-letter instead of seeing the whole page
Forgetting Loses information from earlier in the text Like reading a 500-page book but forgetting chapter 1 by chapter 20

In 2017, Google published "Attention Is All You Need" — the paper that introduced Transformers and changed everything.

What is a Transformer?

A Transformer is a neural network architecture with these key properties:

  • Parallel processing — Reads all words simultaneously (not one-by-one)
  • Attention mechanism — Knows which words to focus on for each decision
  • Position awareness — Knows word order even though it reads in parallel
  • Scalable — Gets better with more data and more parameters (this is why bigger = better usually)

Transformer Architecture Overview:

# Simplified Transformer structure
Input: "The cat sat on the mat"
    ↓
[Token Embeddings + Position Encodings]  # Convert to vectors + add position info
    ↓
[Self-Attention Layer 1]    # Each word looks at all other words
[Feed-Forward Layer 1]     # Process attention results
    ↓
[Self-Attention Layer 2]    # Deeper understanding
[Feed-Forward Layer 2]     # More processing
    ↓
... (repeat 32-80 times for modern LLMs) ...
    ↓
[Output Layer]             # Predict next token probabilities
    ↓
Output: "because" (predicted next word)

The Attention Mechanism (The Secret Sauce)

Self-attention answers the question: "When processing this word, which other words in the sentence should I pay attention to?"

Example:

Sentence: "The animal didn't cross the street because it was too tired"

When processing the word "it", attention helps the model understand that "it" refers to "animal" (not "street"). The attention mechanism assigns high weight to "animal" and low weight to "street" when processing "it".

How Attention Works (Simplified):

For each word, we compute three things:

  1. Query (Q): "What am I looking for?" — what this word needs
  2. Key (K): "What do I contain?" — what this word offers
  3. Value (V): "What information do I provide?" — the actual content

🏠 Analogy: Library Search

Query = Your search question ("I need info about cats")
Key = Book titles on the shelf ("Cat Encyclopedia", "Dog Training", "World History")
Value = The actual book contents

Attention = Match your Query against all Keys → Find best matches → Read those Values

The Math (Simplified):

# Attention formula: Attention(Q, K, V) = softmax(QK^T / √d) × V

# Step 1: Each word creates Q, K, V vectors by multiplying with learned weights
Q = word_embedding × W_query   # "What am I looking for?"
K = word_embedding × W_key     # "What do I have to offer?"
V = word_embedding × W_value   # "Here's my actual information"

# Step 2: Calculate attention scores (how much each word should attend to every other word)
scores = Q @ K.T / sqrt(d_k)   # Higher score = more relevant

# Step 3: Convert to probabilities (sum to 1)
attention_weights = softmax(scores)  # e.g., [0.7, 0.1, 0.05, 0.15]

# Step 4: Weighted sum of values
output = attention_weights @ V  # Mix values based on relevance

Multi-Head Attention

Instead of one attention mechanism, Transformers use multiple "heads" (typically 32-128). Each head learns to focus on different types of relationships:

HeadMight Learn to Focus OnExample
Head 1Grammar/syntax"the" → "cat" (article-noun relationship)
Head 2Coreference"it" → "animal" (pronoun resolution)
Head 3Semantic similarity"happy" → "joyful" (synonyms)
Head 4Position/distanceAdjacent words

All heads work in parallel, then their results are combined. This is why GPUs (which excel at parallel computation) are perfect for Transformers.

Types of Transformer Architectures

TypeHow It WorksUsed ByBest For
Decoder-only Generates text left-to-right, can only look at previous tokens GPT, Llama, Claude, Gemini Text generation, chatbots, coding
Encoder-only Looks at all tokens at once, creates representations BERT, RoBERTa Classification, embeddings, NER
Encoder-Decoder Encoder reads input, Decoder generates output T5, BART, mBART Translation, summarization
💡 Key Insight

All modern chat-style LLMs (GPT-4, Claude, Llama, Gemini) are decoder-only Transformers. They generate text one token at a time, looking only at what came before (not the future). This is called "causal" or "autoregressive" generation.

Production Code: Visualizing Attention

# pip install transformers torch bertviz
from transformers import AutoTokenizer, AutoModel
import torch

# Load a small model to inspect attention
model_name = "bert-base-uncased"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModel.from_pretrained(model_name, output_attentions=True)

# Tokenize a sentence
text = "The cat sat on the mat because it was tired"
inputs = tokenizer(text, return_tensors="pt")

# Get attention weights
with torch.no_grad():
    outputs = model(**inputs)

# outputs.attentions is a tuple: (num_layers, batch, num_heads, seq_len, seq_len)
attentions = outputs.attentions
print(f"Number of layers: {len(attentions)}")
print(f"Attention shape per layer: {attentions[0].shape}")

# Look at what "it" attends to in the last layer
tokens = tokenizer.convert_ids_to_tokens(inputs["input_ids"][0])
it_index = tokens.index("it")

# Average attention across all heads for "it"
last_layer_attn = attentions[-1][0].mean(dim=0)  # Average across heads
it_attention = last_layer_attn[it_index]

print(f"\nWhat does 'it' pay attention to:")
for token, score in sorted(zip(tokens, it_attention.tolist()), key=lambda x: x[1], reverse=True)[:5]:
    print(f"  {token:12s} → {score:.4f}")
# Expected: "cat" will have high attention (it=the cat)

Minimal Transformer Block (PyTorch)

# Simplified transformer block — the core building block of every LLM
import torch
import torch.nn as nn
import math

class SelfAttention(nn.Module):
    """Single-head self-attention (simplified for learning)."""

    def __init__(self, embed_dim):
        super().__init__()
        self.W_q = nn.Linear(embed_dim, embed_dim)
        self.W_k = nn.Linear(embed_dim, embed_dim)
        self.W_v = nn.Linear(embed_dim, embed_dim)
        self.scale = math.sqrt(embed_dim)

    def forward(self, x):
        # x shape: (batch, seq_len, embed_dim)
        Q = self.W_q(x)  # Queries
        K = self.W_k(x)  # Keys
        V = self.W_v(x)  # Values

        # Attention scores: how much each token attends to every other
        scores = torch.matmul(Q, K.transpose(-2, -1)) / self.scale

        # Causal mask: can't look at future tokens (for text generation)
        seq_len = x.size(1)
        mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1).bool()
        scores.masked_fill_(mask, float('-inf'))

        # Softmax → probabilities
        attention_weights = torch.softmax(scores, dim=-1)

        # Weighted sum of values
        output = torch.matmul(attention_weights, V)
        return output

class TransformerBlock(nn.Module):
    """One transformer block = Attention + Feed-Forward + Layer Norms."""

    def __init__(self, embed_dim, ff_dim):
        super().__init__()
        self.attention = SelfAttention(embed_dim)
        self.norm1 = nn.LayerNorm(embed_dim)
        self.norm2 = nn.LayerNorm(embed_dim)
        self.ff = nn.Sequential(
            nn.Linear(embed_dim, ff_dim),
            nn.GELU(),
            nn.Linear(ff_dim, embed_dim),
        )

    def forward(self, x):
        # Attention with residual connection
        x = x + self.attention(self.norm1(x))
        # Feed-forward with residual connection
        x = x + self.ff(self.norm2(x))
        return x

# A "7B parameter" model ≈ 32 of these blocks stacked together
# with embed_dim=4096 and ff_dim=11008

🏭 Industry Standards

  • Decoder-only dominates — All major LLMs in 2024-2026 use decoder-only architecture
  • Flash Attention — Production models use Flash Attention 2 for 2-4x faster training (covered in Ch. 16)
  • RoPE positional encoding — Modern models use Rotary Position Embeddings (Llama, Qwen, Mistral)
  • GQA (Grouped Query Attention) — Optimization where multiple Q heads share K/V heads (saves memory)
  • Layer count — 7B model = ~32 layers, 70B = ~80 layers, 405B = ~126 layers
  • Hidden dimension — 7B = 4096, 70B = 8192, 405B = 16384

📝 Summary

  • Transformers = the architecture behind ALL modern LLMs (invented 2017)
  • Self-attention = each word looks at all other words to understand context
  • Uses Query, Key, Value vectors — like searching a library
  • Multi-head attention = multiple attention mechanisms running in parallel, each learning different patterns
  • Decoder-only = can only look backward (used by GPT, Llama, Claude)
  • Transformers process text in parallel (fast) unlike old RNNs (sequential, slow)

🧠 Mental Model

[Word₁ Word₂ Word₃ ... WordN]
↕ ↕ ↕ ↕
Every word "looks at" every other word
(but future words are masked in generation)

Repeat this 32-80 times = one LLM

Transformer = parallel reading + selective highlighting, stacked many times. Each layer understands the text a little deeper — from surface grammar to deep semantics.

❌ Beginner Mistakes to Avoid

  • Thinking attention is like human attention — It's purely mathematical, not conscious focus.
  • Confusing "Transformer" with "ChatGPT" — Transformer is the architecture; ChatGPT is one product built on it.
  • Ignoring the quadratic cost — Attention cost grows as O(n²) with sequence length. 2x longer text = 4x more compute.
  • Thinking more layers = always better — After a point, adding layers gives diminishing returns without more data.

Dataset Types for LLM Training

Data is the fuel of AI. This chapter explains every type of dataset used to train, fine-tune, and align language models — from raw web crawls to carefully crafted preference pairs.

🏠 Daily Life Analogy

Pre-training data = reading the entire internet. Like a student reading millions of books, articles, and websites to build general knowledge.

Instruction data = homework assignments with answers. "Here's the question, here's how a good student answers it."

Preference data = graded essays. "This answer got an A, this answer got a C — learn the difference."

The Three Stages of Data

1. Pre-training Data

This is the massive corpus used to train a model from scratch. You'll never create this yourself, but understanding it helps you understand model behavior.

2. Supervised Fine-tuning (SFT) Data

This is the dataset format YOU'll use most. It teaches the model to follow instructions and produce helpful answers.

SFT Data Formats:

ChatML Format (Industry Standard):

# Each example is a multi-turn conversation
{
    "messages": [
        {"role": "system", "content": "You are a helpful Python tutor."},
        {"role": "user", "content": "How do I read a file in Python?"},
        {"role": "assistant", "content": "Here's how to read a file:\n\n```python\nwith open('file.txt', 'r') as f:\n    content = f.read()\nprint(content)\n```\n\nThe `with` statement ensures the file is properly closed after reading."}
    ]
}

Alpaca Format (Simple, Popular):

{
    "instruction": "Summarize the following text in one sentence.",
    "input": "Machine learning is a subset of artificial intelligence that enables systems to learn from data...",
    "output": "Machine learning is an AI approach where systems learn patterns from data rather than being explicitly programmed."
}

Completion Format (Simplest):

{
    "text": "### Instruction:\nExplain photosynthesis.\n\n### Response:\nPhotosynthesis is the process by which plants convert sunlight..."
}

3. Preference/Alignment Data

Used for DPO, RLHF, and other alignment methods. Each example shows the model which response is better.

# DPO dataset format — "chosen" is better than "rejected"
{
    "prompt": "How do I lose weight?",
    "chosen": "A healthy approach to weight loss involves: 1) Creating a modest calorie deficit (300-500 cal/day), 2) Regular exercise combining cardio and strength training, 3) Getting 7-9 hours of sleep. Consult a doctor before making major changes.",
    "rejected": "Just stop eating lol. Or try this one weird trick..."
}

from datasets import load_dataset

# Load a popular SFT dataset
dataset = load_dataset("teknium/OpenHermes-2.5", split="train")
print(f"Total examples: {len(dataset):,}")
print(f"Columns: {dataset.column_names}")
print(f"\nFirst example:")
print(dataset[0])

# Load a preference dataset
dpo_data = load_dataset("argilla/ultrafeedback-binarized-preferences", split="train")
print(f"\nDPO dataset size: {len(dpo_data):,}")

# Filter dataset by topic
code_examples = dataset.filter(lambda x: "python" in str(x.get("conversations", "")).lower())

Creating Your Own SFT Dataset

import json
from datasets import Dataset

# Method 1: From a list of conversations (ChatML format)
my_data = [
    {
        "messages": [
            {"role": "system", "content": "You are a customer support agent for TechCo."},
            {"role": "user", "content": "My laptop won't turn on"},
            {"role": "assistant", "content": "I'm sorry to hear that! Let's troubleshoot:\n\n1. Is the laptop plugged in? Check the power indicator light.\n2. Try holding the power button for 15 seconds.\n3. Remove the battery (if removable) and plug in directly.\n\nLet me know what happens with step 1."}
        ]
    },
    {
        "messages": [
            {"role": "system", "content": "You are a customer support agent for TechCo."},
            {"role": "user", "content": "How do I return a product?"},
            {"role": "assistant", "content": "You can return any product within 30 days of purchase:\n\n1. Go to techco.com/returns\n2. Enter your order number\n3. Print the shipping label\n4. Drop off at any UPS location\n\nRefunds process within 5-7 business days."}
        ]
    }
]

# Save as JSONL (industry standard format)
with open("my_dataset.jsonl", "w") as f:
    for example in my_data:
        f.write(json.dumps(example) + "\n")

# Convert to HuggingFace Dataset
hf_dataset = Dataset.from_list(my_data)
print(hf_dataset)

Dataset Quality Analysis

from datasets import load_dataset
import statistics

def analyze_dataset(dataset_name: str, split: str = "train"):
    """Comprehensive dataset quality check."""
    ds = load_dataset(dataset_name, split=split)

    print(f"📊 Dataset: {dataset_name}")
    print(f"   Total examples: {len(ds):,}")
    print(f"   Columns: {ds.column_names}")

    # Analyze text lengths
    if "messages" in ds.column_names:
        lengths = [sum(len(m["content"]) for m in ex["messages"]) for ex in ds]
    elif "text" in ds.column_names:
        lengths = [len(ex["text"]) for ex in ds]
    else:
        lengths = [len(str(ex)) for ex in ds]

    print(f"   Avg length: {statistics.mean(lengths):,.0f} chars")
    print(f"   Median length: {statistics.median(lengths):,.0f} chars")
    print(f"   Min/Max: {min(lengths):,} / {max(lengths):,} chars")

    # Check for duplicates
    if "text" in ds.column_names:
        unique = len(set(ds["text"]))
        print(f"   Unique examples: {unique:,} ({unique/len(ds)*100:.1f}%)")
        print(f"   Duplicates: {len(ds) - unique:,}")

    return ds

# Analyze popular datasets
analyze_dataset("tatsu-lab/alpaca")

🏭 Industry Standards

  • Quality > Quantity — 5,000 excellent examples beat 500,000 mediocre ones. Microsoft's Phi models proved this.
  • JSONL format — Industry standard for dataset files. One JSON object per line.
  • ChatML format — Standard for conversational data (system/user/assistant roles). Used by OpenAI, TRL, Axolotl.
  • HuggingFace Hub — Standard platform for sharing datasets. Use datasets library to load.
  • Deduplication is mandatory — Duplicate examples cause memorization, not learning.
  • Diverse data — Mix topics, difficulty levels, and response styles for robust models.
  • 1,000-10,000 examples — Sweet spot for fine-tuning. More isn't always better.

📝 Summary

  • Pre-training data = trillions of tokens from the internet (you won't create this)
  • SFT data = instruction-response pairs in ChatML or Alpaca format (YOUR main focus)
  • Preference data = chosen/rejected pairs for alignment (DPO/RLHF)
  • Quality matters far more than quantity for fine-tuning
  • Use JSONL format, ChatML structure, push to HuggingFace Hub
  • Always deduplicate and analyze your data before training

🧠 Mental Model

Pre-training: "Read the internet" → General knowledge
SFT: "Here's how to answer questions" → Instruction following
Preference: "This answer is better than that one" → Quality & safety

❌ Beginner Mistakes to Avoid

  • Using raw, uncleaned data — Garbage in = garbage out. Clean your data thoroughly.
  • Too much data of low quality — 1,000 curated examples > 100,000 noisy ones.
  • Wrong format — If your trainer expects ChatML but you give it Alpaca format, training will silently fail.
  • No system prompts — Without a system message, the model won't learn consistent persona/behavior.
  • Imbalanced topics — 90% code + 10% writing = model forgets how to write well.

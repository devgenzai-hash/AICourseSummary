Synthetic Data Generation

Don't have enough training data? Generate it! Learn how to use AI to create high-quality training datasets — the technique behind models like Phi, Orca, and WizardLM.

🏠 Daily Life Analogy

Synthetic data = Practice exam questions written by a teacher. A teacher (GPT-4) creates practice problems and model answers. Students (your model) learn from these. The practice problems aren't "real" exam questions, but they teach the same skills.

Seed data + Variations = One recipe → a whole cookbook. You start with 10 real customer support tickets, then generate 10,000 variations covering different products, issues, and tones.

Why Synthetic Data?

ProblemSynthetic SolutionReal-World Example
Not enough dataGenerate thousands of examples from a few seedsStartup with 50 customer emails → 5,000 training pairs
Privacy concernsGenerate similar-but-fake dataMedical records → synthetic patient conversations
Expensive labelingAI labels instead of humans ($0.001 vs $1 per example)Annotation that would cost $100K → $100
Domain gapsGenerate edge cases that rarely occur naturallyCreating adversarial/tricky examples
Bootstrapping new tasksCreate training data for tasks with no existing datasetTraining a model for your custom API documentation

Synthetic Data Techniques

1. Seed-and-Expand (Most Common)

Start with a few real examples, use a strong model to generate more:

# Seed-and-Expand: Generate training data from a few examples
from openai import OpenAI
import json

client = OpenAI()

# Your seed examples (real data you have)
seed_examples = [
    {
        "instruction": "How do I reset my password?",
        "response": "Go to Settings > Security > Reset Password. Enter your current password, then type your new password twice. Click Save."
    },
    {
        "instruction": "My payment failed, what do I do?",
        "response": "Payment failures usually happen due to insufficient funds or expired cards. Please check your card details in Settings > Billing and try again."
    }
]

def generate_synthetic_examples(seeds, num_to_generate=20, domain="customer support for a SaaS product"):
    """Generate new training examples based on seed data."""

    prompt = f"""You are a dataset generator. Based on these example Q&A pairs from {domain}, 
generate {num_to_generate} NEW, diverse examples in the same style and format.

SEED EXAMPLES:
{json.dumps(seeds, indent=2)}

REQUIREMENTS:
- Cover different topics/scenarios within the domain
- Vary difficulty levels (simple to complex)
- Keep responses helpful, accurate, and professional
- Include edge cases and unusual scenarios
- Format: JSON array of {{"instruction": "...", "response": "..."}}

Generate exactly {num_to_generate} examples:"""

    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.9,  # Higher = more diverse
        max_tokens=4000
    )

    # Parse the generated examples
    generated = json.loads(response.choices[0].message.content)
    return generated

# Generate!
synthetic_data = generate_synthetic_examples(seed_examples, num_to_generate=20)
print(f"Generated {len(synthetic_data)} examples")
print(json.dumps(synthetic_data[0], indent=2))

2. Self-Instruct Method (Used by Alpaca)

# Self-Instruct: Model generates both instructions AND responses
from openai import OpenAI
import json
import random

client = OpenAI()

# Categories to ensure diversity
categories = [
    "coding", "math", "creative writing", "analysis",
    "explanation", "summarization", "translation",
    "brainstorming", "debugging", "planning"
]

def self_instruct_batch(category: str, n: int = 5):
    """Generate instruction-response pairs for a category."""
    prompt = f"""Generate {n} diverse instruction-response pairs for the category: {category}

Each pair should:
- Have a clear, specific instruction
- Have a detailed, high-quality response  
- Vary in complexity (some easy, some hard)
- Be self-contained (no external context needed)

Return as JSON array: [{{"instruction": "...", "response": "..."}}]"""

    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": prompt}],
        temperature=1.0,
        max_tokens=4000
    )

    return json.loads(response.choices[0].message.content)

# Generate across all categories
all_data = []
for category in categories:
    batch = self_instruct_batch(category, n=10)
    all_data.extend(batch)
    print(f"✓ {category}: {len(batch)} examples")

print(f"\nTotal: {len(all_data)} examples across {len(categories)} categories")

3. Evol-Instruct (Used by WizardLM)

# Evol-Instruct: Progressively make instructions more complex
from openai import OpenAI
import json

client = OpenAI()

def evolve_instruction(simple_instruction: str, method: str = "deepen") -> str:
    """Make an instruction more complex using evolution strategies."""
    
    evolution_prompts = {
        "deepen": f"Make this instruction more complex by adding constraints, requiring deeper reasoning, or asking for more detailed output:\n\nOriginal: {simple_instruction}\n\nEvolved (more complex version):",
        "broaden": f"Expand this instruction to cover a wider scope or combine multiple related tasks:\n\nOriginal: {simple_instruction}\n\nEvolved (broader version):",
        "concretize": f"Make this instruction more specific with concrete details, real-world context, and specific constraints:\n\nOriginal: {simple_instruction}\n\nEvolved (more specific version):",
    }

    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": evolution_prompts[method]}],
        temperature=0.8,
        max_tokens=500
    )
    return response.choices[0].message.content.strip()

# Example: Evolve a simple instruction through 3 levels
simple = "Write a Python function to sort a list"

level1 = evolve_instruction(simple, "deepen")
# → "Write a Python function that implements merge sort, handles lists with mixed types,
#    and returns both the sorted list and the number of comparisons made"

level2 = evolve_instruction(level1, "concretize")
# → "Write a production-ready Python function for a e-commerce platform that sorts
#    products by price, with tie-breaking by rating, handling None values..."

print(f"Original: {simple}")
print(f"Level 1: {level1}")
print(f"Level 2: {level2}")

4. Generating Preference Pairs for DPO

# Generate preference data: good answer vs bad answer
from openai import OpenAI
import json

client = OpenAI()

def generate_preference_pair(instruction: str) -> dict:
    """Generate a chosen (good) and rejected (bad) response pair."""

    # Generate a GOOD response
    good_prompt = f"Answer this question with a helpful, detailed, accurate response:\n\n{instruction}"
    good_response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": good_prompt}],
        temperature=0.3
    ).choices[0].message.content

    # Generate a BAD response (intentionally flawed)
    bad_prompt = f"""Answer this question, but make the response have these flaws:
- Be somewhat vague and unhelpful  
- Include minor inaccuracies
- Be overly brief or miss key details
- Use a slightly dismissive tone

Question: {instruction}"""
    bad_response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": bad_prompt}],
        temperature=0.7
    ).choices[0].message.content

    return {
        "prompt": instruction,
        "chosen": good_response,
        "rejected": bad_response
    }

# Generate preference pairs
questions = [
    "How do I handle errors in Python?",
    "What's the difference between SQL and NoSQL?",
    "How do I improve my public speaking?",
]

dpo_dataset = [generate_preference_pair(q) for q in questions]

# Save for DPO training
with open("dpo_data.jsonl", "w") as f:
    for pair in dpo_dataset:
        f.write(json.dumps(pair) + "\n")

Production Data Pipeline

# Full production pipeline for synthetic data generation
import json
import hashlib
from openai import OpenAI
from datasets import Dataset
from concurrent.futures import ThreadPoolExecutor
from typing import Optional
import time

client = OpenAI()

class SyntheticDataPipeline:
    """Production-grade synthetic data generation pipeline."""

    def __init__(self, model="gpt-4o-mini", max_workers=5):
        self.model = model
        self.max_workers = max_workers
        self.generated = []
        self.seen_hashes = set()  # Deduplication

    def _hash_text(self, text: str) -> str:
        return hashlib.md5(text.lower().strip().encode()).hexdigest()

    def generate_batch(self, prompt: str, n: int = 10) -> list:
        """Generate a batch of examples with deduplication."""
        response = client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            temperature=0.9,
            max_tokens=4000
        )

        try:
            examples = json.loads(response.choices[0].message.content)
        except json.JSONDecodeError:
            return []

        # Deduplicate
        unique = []
        for ex in examples:
            h = self._hash_text(str(ex.get("instruction", ex.get("messages", ""))))
            if h not in self.seen_hashes:
                self.seen_hashes.add(h)
                unique.append(ex)
        return unique

    def validate_example(self, example: dict) -> bool:
        """Basic quality checks."""
        instruction = example.get("instruction", "")
        response = example.get("response", "")

        if len(instruction) < 10:  return False
        if len(response) < 50:  return False
        if instruction == response:  return False
        return True

    def run(self, seed_data: list, target_count: int = 1000, domain: str = "general"):
        """Run the full pipeline."""
        print(f"🚀 Generating {target_count} examples for domain: {domain}")

        while len(self.generated) < target_count:
            prompt = f"""Generate 10 diverse instruction-response pairs for: {domain}
Based on these seed examples: {json.dumps(seed_data[:3])}
Return JSON array: [{{"instruction": "...", "response": "..."}}]"""

            batch = self.generate_batch(prompt)
            valid = [ex for ex in batch if self.validate_example(ex)]
            self.generated.extend(valid)
            print(f"  Progress: {len(self.generated)}/{target_count}")
            time.sleep(0.5)  # Rate limiting

        # Convert to HuggingFace Dataset
        dataset = Dataset.from_list(self.generated[:target_count])
        print(f"✅ Generated {len(dataset)} validated examples")
        return dataset

# Usage
pipeline = SyntheticDataPipeline(model="gpt-4o-mini")
seeds = [{"instruction": "How do I deploy a Flask app?", "response": "..."}]
dataset = pipeline.run(seeds, target_count=100, domain="web development")
dataset.save_to_disk("./my_synthetic_dataset")

🏭 Industry Standards

  • Microsoft's Phi models — Trained almost entirely on synthetic data. Proves synthetic data works at scale.
  • Orca method — Use GPT-4 to generate detailed reasoning traces, then train smaller models on them.
  • WizardLM's Evol-Instruct — Progressively evolve simple instructions into complex ones for better training.
  • Always use the best model available as teacher — GPT-4o or Claude as teacher, train your 8B student model.
  • Validate before training — Run quality checks, remove duplicates, check for hallucinated "facts".
  • Mix synthetic + real data — Best results come from 80% synthetic + 20% real human-written data.
  • Cost: ~$50-200 for 10K high-quality examples using GPT-4o-mini as generator.

📝 Summary

  • Synthetic data = using a strong AI model to generate training data for a smaller model
  • Seed-and-Expand: Start with real examples, generate variations
  • Self-Instruct: Model generates both questions and answers
  • Evol-Instruct: Progressively increase instruction complexity
  • Always deduplicate, validate quality, and mix with real data
  • Cost-effective: $50-200 for a usable dataset vs $10,000+ for human annotation

🧠 Mental Model

Teacher (GPT-4) → Generates training examples → Student (your 8B model) learns

Real data (seeds) → Expand → Validate → Deduplicate → Final dataset
[10 examples] → [10,000 examples] → [8,000 pass QA] → [7,500 unique] → TRAIN!

❌ Beginner Mistakes to Avoid

  • Not deduplicating — AI generators often repeat patterns. Always hash and deduplicate.
  • Using a weak teacher model — Don't generate data with GPT-3.5 if you can afford GPT-4. Quality flows downhill.
  • No validation step — Generated data often has errors. Spot-check at least 5% manually.
  • Temperature too low — Use 0.8-1.0 for diversity. Low temp = repetitive data.
  • Ignoring ToS — Some API providers restrict using outputs to train competing models. Check terms.

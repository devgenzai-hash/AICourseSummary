## 2) Skills Demand Analysis (from extracted job descriptions)

Most demanded skills across sampled postings:
1. **Selenium**
2. **Jira**
3. **CI/CD**
4. **SQL**
5. **Java**
6. **API Testing**
7. **Manual Testing**
8. **TestNG / Cucumber**
9. **Agile/Scrum**
10. **Performance Testing**

### What this means
- Market is hybrid: manual + automation profiles are still common.
- API + DB validation (SQL + API) is now baseline for many mid-level QA roles.
- Modern stack demand is rising: Playwright, CI/CD integration, cloud QA (Azure/AWS).
- Senior roles increasingly mention framework ownership, defect triage, and QA strategy.

## 4) Role Segmentation

### Entry-level / Junior QA
- Strong emphasis: manual testing, test cases, regression, STLC basics, SQL basics.
- Typical India compensation often appears in lower bands (job-filter and posting evidence).

### Mid-level QA Automation
- Strong emphasis: Selenium + Java/Python, API testing, CI/CD, Git, Jira.
- This appears to be the highest-volume hiring segment.

### Senior QA / Lead / SDET
- Strong emphasis: framework design, automation strategy, DevOps integration, non-functional testing, mentoring.
- Compensation bands widen significantly.

---

## 5) India-specific observations (from Indian portals)

- Demand is highly metro-centric: Bengaluru, Hyderabad, Pune, NCR dominate.
- Naukri filter distribution indicates large hiring spread across salary bands, with strongest visible concentration in 3–10 LPA buckets for software tester search filters.
- QA automation searches show lower absolute count than broad software tester but stronger tool-specific requirements (Selenium, CI/CD, API, Java).

---

## 6) Practical Upskilling Roadmap (for maximum employability)

Priority order:
1. Selenium + Java (or Python)
2. API testing (Postman/REST validation) + SQL
3. CI/CD basics (Jenkins/GitHub Actions/GitLab)
4. Jira workflow + defect lifecycle
5. TestNG/Cucumber (BDD)
6. Performance basics (JMeter/LoadRunner)
7. Playwright (fast-growing modern web automation)

---

## 7) Data Quality & Method Notes

- This report intentionally uses **job portals only**.
- Some portals block full scraping for all pages; therefore:
  - Detailed extraction is based on accessible listing snippets and role pages.
  - A verified structured sample dataset was produced (see CSV files).
  - High-level demand counts are taken from portal-reported totals/filters.
- Result: strong directional and tactical accuracy for skills, salary ranges, location demand, and role trends.

---

## 8) Executive Summary

- QA hiring remains strong globally and very strong in India.
- Highest demand cluster: **automation-capable QA engineers** with **Selenium + API + SQL + CI/CD**.
- Manual testing remains relevant, but standalone manual-only demand is lower than hybrid/manual+automation profiles.
- India salary spread is broad; practical market center is still mid-band, but top-end automation/SDET roles can be significantly higher.
- Best ROI skill path: **Selenium + Java/Python + API/SQL + CI/CD + Playwright**.

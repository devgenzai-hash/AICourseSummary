Chapter 5: Stage 2 — Supervised Fine-Tuning (SFT)

Teaching Gemma to follow instructions, answer questions, and have conversations about Hindu scriptures using the TRL SFTTrainer with QLoRA.

🎯 What is Supervised Fine-Tuning?

Non-Technical Explanation

After CPT, the model is like a brilliant reader who has absorbed all the scriptures — but can't hold a conversation. SFT is like tutoring practice: you show it thousands of example conversations (question → answer), and it learns the pattern of responding helpfully to queries about scriptures.

Technical Explanation

SFT minimizes the cross-entropy loss on the assistant responses only. Given an input conversation, the model learns to predict the assistant's tokens while ignoring the user's tokens in the loss computation. This teaches it:

  • How to format responses (structure, length, tone)
  • When to provide Sanskrit quotes vs plain explanations
  • How to handle multilingual queries (Hindi question → English answer)
  • Instruction-following behavior (summarize, explain, compare, translate)

💻 Complete SFT Training Code

"""
Supervised Fine-Tuning for Hindu Scripture Q&A
===============================================
Trains Gemma to follow instructions about scriptures using QLoRA.
Builds on CPT adapter from Chapter 4 (or starts from base model).

Usage:
    python sft_train.py

Hardware: 1x A100 40GB (or 1x RTX 4090 24GB for 12B model)
Time: ~6-12 hours for 50K examples
"""
import torch
from datasets import load_dataset
from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig
from peft import LoraConfig, PeftModel, prepare_model_for_kbit_training
from trl import SFTTrainer, SFTConfig

# ============================================
# CONFIGURATION
# ============================================
# Option A: Start from CPT model (recommended if you did CPT)
BASE_MODEL = "google/gemma-3-27b-it"
CPT_ADAPTER = "./checkpoints/cpt_lora/final"  # Set to None if skipping CPT

# Option B: Start directly from base instruct model
# BASE_MODEL = "google/gemma-3-27b-it"
# CPT_ADAPTER = None

DATASET_PATH = "./datasets/sft_scripture_data.jsonl"
OUTPUT_DIR = "./checkpoints/sft_lora"

# Hyperparameters
LEARNING_RATE = 1e-4        # Higher than CPT since only training LoRA on new task
NUM_EPOCHS = 3
BATCH_SIZE = 2
GRADIENT_ACCUMULATION = 8   # Effective batch = 16
MAX_SEQ_LENGTH = 4096       # Longer for multi-turn conversations

# ============================================
# STEP 1: Load Model
# ============================================
print("📦 Loading model...")

tokenizer = AutoTokenizer.from_pretrained(BASE_MODEL)
if tokenizer.pad_token is None:
    tokenizer.pad_token = tokenizer.eos_token

# 4-bit quantization config
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,
)

model = AutoModelForCausalLM.from_pretrained(
    BASE_MODEL,
    quantization_config=bnb_config,
    device_map="auto",
    torch_dtype=torch.bfloat16,
    attn_implementation="flash_attention_2",
)

# If we have a CPT adapter, load it first
if CPT_ADAPTER:
    print(f"📎 Loading CPT adapter from {CPT_ADAPTER}...")
    model = PeftModel.from_pretrained(model, CPT_ADAPTER)
    model = model.merge_and_unload()  # Merge CPT weights into base
    # Now we'll add fresh LoRA adapters for SFT

model = prepare_model_for_kbit_training(model)

# ============================================
# STEP 2: Configure NEW LoRA for SFT
# ============================================
print("🔧 Configuring LoRA for SFT...")

lora_config = LoraConfig(
    r=32,                    # Can be lower than CPT since task is simpler
    lora_alpha=16,
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
    target_modules=[
        "q_proj", "k_proj", "v_proj", "o_proj",
        "gate_proj", "up_proj", "down_proj",
    ],
)

# ============================================
# STEP 3: Load SFT Dataset
# ============================================
print("📊 Loading SFT dataset...")

dataset = load_dataset("json", data_files=DATASET_PATH, split="train")

# Split into train/eval (90/10)
split = dataset.train_test_split(test_size=0.1, seed=42)
train_dataset = split["train"]
eval_dataset = split["test"]

print(f"  Train: {len(train_dataset)} examples")
print(f"  Eval:  {len(eval_dataset)} examples")

# Preview an example
print(f"\n  Example conversation:")
example = train_dataset[0]
for msg in example["messages"]:
    role = msg["role"]
    content = msg["content"][:100]
    print(f"    [{role}] {content}...")

# ============================================
# STEP 4: Training Configuration
# ============================================
training_args = SFTConfig(
    output_dir=OUTPUT_DIR,
    
    # Training
    num_train_epochs=NUM_EPOCHS,
    per_device_train_batch_size=BATCH_SIZE,
    per_device_eval_batch_size=BATCH_SIZE,
    gradient_accumulation_steps=GRADIENT_ACCUMULATION,
    
    # Optimizer
    learning_rate=LEARNING_RATE,
    lr_scheduler_type="cosine",
    warmup_ratio=0.05,                  # 5% warmup
    weight_decay=0.01,
    optim="paged_adamw_8bit",
    max_grad_norm=1.0,
    
    # Precision & Memory
    bf16=True,
    gradient_checkpointing=True,
    
    # Sequence handling
    max_seq_length=MAX_SEQ_LENGTH,
    packing=False,                      # Don't pack for SFT (each conv is one example)
    
    # CRITICAL: Only compute loss on assistant responses
    # This ensures the model learns to RESPOND, not to mimic user queries
    assistant_only_loss=True,
    
    # Logging
    logging_steps=10,
    logging_dir=f"{OUTPUT_DIR}/logs",
    report_to="wandb",
    run_name="gemma-scripture-sft",
    
    # Saving & Eval
    eval_strategy="steps",
    eval_steps=200,
    save_strategy="steps",
    save_steps=200,
    save_total_limit=3,
    load_best_model_at_end=True,
    metric_for_best_model="eval_loss",
    
    seed=42,
)

# ============================================
# STEP 5: Train!
# ============================================
print("\n🚀 Starting SFT training...")

trainer = SFTTrainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    processing_class=tokenizer,
    peft_config=lora_config,
)

# Train
result = trainer.train()

# Save
print("\n💾 Saving model...")
trainer.save_model(f"{OUTPUT_DIR}/final")
tokenizer.save_pretrained(f"{OUTPUT_DIR}/final")

print(f"\n{'='*50}")
print(f"✅ SFT Training Complete!")
print(f"   Train Loss: {result.training_loss:.4f}")
print(f"   Saved to: {OUTPUT_DIR}/final")
print(f"{'='*50}")

📚 Data Creation Strategies

Strategy 1: Self-Instruct (Automated, Scalable)

"""
Self-Instruct: Use a powerful model to generate diverse training data.
Cost: ~$50-200 for 50K examples using GPT-4o-mini
"""
import json
import random

SEED_TASKS = [
    "Explain the meaning of Bhagavad Gita Chapter {ch}, Verse {v}.",
    "What is the concept of {concept} in Hindu philosophy?",
    "Compare {school1} and {school2} interpretations of {topic}.",
    "Tell the story of {character} from the {epic}.",
    "Translate this Sanskrit verse: {verse}",
    "How does {scripture} address the topic of {topic}?",
    "{hindi_question}",
]

CONCEPTS = ["Dharma", "Karma", "Moksha", "Maya", "Atman", "Brahman", "Samsara", 
            "Yoga", "Bhakti", "Jnana", "Ahimsa", "Tapas", "Vairagya"]

SCHOOLS = ["Advaita", "Vishishtadvaita", "Dvaita", "Yoga", "Samkhya", "Nyaya"]

def generate_diverse_prompts(n: int = 1000) -> list:
    """Generate diverse prompts for SFT data creation."""
    prompts = []
    
    for _ in range(n):
        template = random.choice(SEED_TASKS)
        
        prompt = template.format(
            ch=random.randint(1, 18),
            v=random.randint(1, 78),
            concept=random.choice(CONCEPTS),
            school1=random.choice(SCHOOLS),
            school2=random.choice(SCHOOLS),
            topic=random.choice(CONCEPTS),
            character=random.choice(["Rama", "Krishna", "Arjuna", "Draupadi", 
                                      "Hanuman", "Bhishma", "Yudhishthira"]),
            epic=random.choice(["Ramayana", "Mahabharata"]),
            verse="कर्मण्येवाधिकारस्ते मा फलेषु कदाचन",
            scripture=random.choice(["Bhagavad Gita", "Yoga Sutras", 
                                      "Katha Upanishad", "Mandukya Upanishad"]),
            hindi_question=random.choice([
                "गीता में कर्मयोग क्या है?",
                "उपनिषदों का मुख्य संदेश क्या है?",
                "रामायण से हमें क्या शिक्षा मिलती है?",
                "योग के आठ अंग कौन से हैं?",
            ])
        )
        prompts.append(prompt)
    
    return prompts

Strategy 2: Distillation from Stronger Model

"""
Distillation: Get a powerful model (GPT-4, Claude) to answer your prompts,
then use those answers as training data for Gemma.
This is the fastest way to get high-quality SFT data.
"""
import openai
import json
import time

client = openai.OpenAI(api_key="your-key")

def distill_from_teacher(
    prompts: list,
    output_path: str,
    teacher_model: str = "gpt-4o",
    system_prompt: str = SYSTEM_PROMPT,
    batch_size: int = 10,
    delay: float = 0.5  # Rate limiting
):
    """Generate training data by distilling from a stronger model."""
    
    with open(output_path, 'w', encoding='utf-8') as f:
        for i, prompt in enumerate(prompts):
            try:
                response = client.chat.completions.create(
                    model=teacher_model,
                    messages=[
                        {"role": "system", "content": system_prompt},
                        {"role": "user", "content": prompt}
                    ],
                    temperature=0.7,
                    max_tokens=2048,
                )
                
                answer = response.choices[0].message.content
                
                # Save as SFT format
                example = {
                    "messages": [
                        {"role": "system", "content": system_prompt},
                        {"role": "user", "content": prompt},
                        {"role": "assistant", "content": answer}
                    ]
                }
                
                f.write(json.dumps(example, ensure_ascii=False) + '\n')
                
                if (i + 1) % 100 == 0:
                    print(f"  Generated {i+1}/{len(prompts)} examples...")
                
                time.sleep(delay)
                
            except Exception as e:
                print(f"  Error on prompt {i}: {e}")
                continue
    
    print(f"✓ Generated {i+1} examples → {output_path}")

Strategy 3: Manual Curation (Highest Quality)

📈 Evaluating During Training

"""
Custom evaluation metrics for SFT training.
Beyond just loss — measure if the model is actually learning to be helpful.
"""
from transformers import TrainerCallback
import torch

class SFTEvaluationCallback(TrainerCallback):
    """Periodically generate responses to test prompts during training."""
    
    def __init__(self, tokenizer, eval_prompts, eval_every_steps=500):
        self.tokenizer = tokenizer
        self.eval_prompts = eval_prompts
        self.eval_every_steps = eval_every_steps
    
    def on_step_end(self, args, state, control, model=None, **kwargs):
        if state.global_step % self.eval_every_steps != 0:
            return
        
        print(f"\n{'='*40}")
        print(f"Generation check at step {state.global_step}")
        print(f"{'='*40}")
        
        model.eval()
        for prompt in self.eval_prompts[:3]:
            messages = [
                {"role": "system", "content": "You are a Hindu scripture scholar."},
                {"role": "user", "content": prompt}
            ]
            
            inputs = self.tokenizer.apply_chat_template(
                messages,
                add_generation_prompt=True,
                return_tensors="pt"
            ).to(model.device)
            
            with torch.no_grad():
                outputs = model.generate(
                    inputs,
                    max_new_tokens=200,
                    temperature=0.7,
                    do_sample=True,
                )
            
            response = self.tokenizer.decode(
                outputs[0][inputs.shape[-1]:],
                skip_special_tokens=True
            )
            print(f"\n📝 Q: {prompt}")
            print(f"💬 A: {response[:300]}...")
        
        model.train()

💡 SFT Best Practices

✅ Do's
  • Use assistant_only_loss=True — only train on responses, not prompts
  • Include diverse question types (factual, philosophical, comparative, translation)
  • Mix languages in training data matching your target usage
  • Include both short and long responses
  • Add system prompt to every example for consistency
  • Use packing=False for SFT (each conversation is one unit)
❌ Don'ts
  • Don't train for too many epochs (3 max) — causes overfitting
  • Don't use too high learning rate (>5e-4 with LoRA)
  • Don't include low-quality or factually wrong examples
  • Don't have all responses be the same length
  • Don't skip evaluation — check model outputs every 500 steps

Chapter 3: Dataset Format Requirements

The exact data formats needed for each training stage — CPT, SFT, and DPO — with scripture-specific examples and code to create them.

📋 Format Overview

💡 Three Different Formats for Three Different Stages

Each training stage requires data in a different format. Think of it as: raw reading material (CPT), textbook exercises (SFT), and graded essays (DPO).

Stage Format Purpose Example
CPT Plain text / JSONL with "text" field Teach domain vocabulary & knowledge {"text": "The Bhagavad Gita..."}
SFT Conversational messages Teach instruction-following {"messages": [{"role": "user"...}]}
DPO Prompt + chosen + rejected Align with quality preferences {"prompt":..., "chosen":..., "rejected":...}

📄 CPT (Continued Pre-Training) Format

What It Is

For continued pre-training, you need raw text — just the scripture content as-is. The model reads this text and learns the domain vocabulary, writing patterns, factual knowledge, and the structure of Hindu philosophical discourse.

Format Specification

# Format: JSONL (JSON Lines) — one document per line
# Each line is a JSON object with a "text" field

# Example file: corpus_cpt.jsonl
{"text": "अथ प्रथमोऽध्यायः। धर्मक्षेत्रे कुरुक्षेत्रे समवेता युयुत्सवः। मामकाः पाण्डवाश्चैव किमकुर्वत सञ्जय॥१॥ धृतराष्ट्र उवाच — हे सञ्जय! धर्मभूमि कुरुक्षेत्र में एकत्र हुए युद्ध की इच्छावाले मेरे और पाण्डु के पुत्रों ने क्या किया?"}
{"text": "The Bhagavad Gita, often referred to as the Gita, is a 700-verse Hindu scripture that is part of the epic Mahabharata. It is a dialogue between Prince Arjuna and Lord Krishna, who serves as his charioteer. The discourse takes place on the battlefield of Kurukshetra."}
{"text": "ईशावास्यमिदं सर्वं यत्किञ्च जगत्यां जगत्। तेन त्यक्तेन भुञ्जीथा मा गृधः कस्यस्विद्धनम्॥ Isha Upanishad begins with the profound declaration that everything in this universe is pervaded by the Lord."}

Best Practices for CPT Data

  • Chunk size: Each document should be 512-4096 tokens. Too short = wasted padding. Too long = truncated.
  • Include all languages: Mix Hindi, Sanskrit, and English in the corpus (proportional to your target use case)
  • Include both original and translations: Sanskrit verses with Hindi/English translations helps the model learn cross-lingual connections
  • Include commentaries: Shankaracharya's bhashya, Ramanuja's commentary — these teach interpretive patterns

Code: Create CPT Dataset from Raw Text

"""
Convert cleaned text files into CPT-ready JSONL format.
Handles chunking long documents into optimal training segments.
"""
import json
from pathlib import Path
from transformers import AutoTokenizer

def create_cpt_dataset(
    input_dir: str,
    output_path: str,
    model_name: str = "google/gemma-3-27b-it",
    max_tokens: int = 2048,
    overlap_tokens: int = 128
):
    """
    Create CPT dataset with intelligent chunking.
    
    Args:
        input_dir: Directory with cleaned .txt files
        output_path: Output JSONL file path
        model_name: Model tokenizer to use for token counting
        max_tokens: Maximum tokens per chunk
        overlap_tokens: Overlap between chunks (for context continuity)
    """
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    
    chunks_created = 0
    
    with open(output_path, 'w', encoding='utf-8') as out_file:
        for txt_file in sorted(Path(input_dir).glob("*.txt")):
            text = txt_file.read_text(encoding='utf-8')
            
            # Tokenize the full document
            tokens = tokenizer.encode(text)
            
            # Split into chunks with overlap
            start = 0
            while start < len(tokens):
                end = start + max_tokens
                chunk_tokens = tokens[start:end]
                
                # Decode back to text
                chunk_text = tokenizer.decode(chunk_tokens, skip_special_tokens=True)
                
                # Write as JSONL
                record = {
                    "text": chunk_text,
                    "source": txt_file.name,
                    "chunk_id": chunks_created
                }
                out_file.write(json.dumps(record, ensure_ascii=False) + '\n')
                chunks_created += 1
                
                # Move forward with overlap
                start = end - overlap_tokens
    
    print(f"✓ Created {chunks_created} chunks → {output_path}")
    return chunks_created


# Usage
create_cpt_dataset(
    input_dir="./processed_corpus/",
    output_path="./datasets/cpt_corpus.jsonl",
    max_tokens=2048
)

💬 SFT (Supervised Fine-Tuning) Format

What It Is

SFT data teaches the model to follow instructions. Each example is a conversation between a user asking a question about Hindu scriptures and an assistant providing a helpful, accurate answer.

Format Specification

# Format 1: Conversational (RECOMMENDED for chat models)
# Each example is a list of messages with roles

{
  "messages": [
    {"role": "system", "content": "You are a knowledgeable scholar of Hindu scriptures..."},
    {"role": "user", "content": "What does the Bhagavad Gita say about duty?"},
    {"role": "assistant", "content": "The Bhagavad Gita extensively discusses..."}
  ]
}

# Format 2: Prompt-Completion (simpler, also supported)
{
  "prompt": "Explain the concept of Dharma in the Mahabharata.",
  "completion": "Dharma in the Mahabharata is a multifaceted concept..."
}

Code: Generate SFT Data using a Stronger Model

"""
Generate high-quality SFT training data using a stronger model (Self-Instruct method).
Uses an existing powerful model to create instruction-response pairs from raw text.
"""
import json
import openai  # or any API-compatible provider
from typing import List, Dict

# Configure your API (Claude, GPT-4, or similar)
client = openai.OpenAI(
    api_key="your-api-key",
    base_url="https://api.openai.com/v1"  # or your provider
)

SYSTEM_PROMPT = """You are a Hindu scripture expert helping create training data.
Given a passage from a Hindu scripture, generate 3-5 diverse question-answer pairs.

Rules:
1. Questions should be in a mix of Hindi and English
2. Answers must be accurate, detailed, and cite specific references
3. Include Sanskrit terms with translations
4. Vary question complexity (simple factual → deep philosophical)
5. Format answers with clear structure (bullet points, numbered lists where appropriate)

Output as JSON array:
[{"question": "...", "answer": "..."}]
"""

def generate_sft_pairs(passage: str, source: str) -> List[Dict]:
    """Generate instruction-response pairs from a scripture passage."""
    
    response = client.chat.completions.create(
        model="gpt-4o",  # Use the best available model
        messages=[
            {"role": "system", "content": SYSTEM_PROMPT},
            {"role": "user", "content": f"Source: {source}\n\nPassage:\n{passage}"}
        ],
        temperature=0.7,
        max_tokens=4096,
        response_format={"type": "json_object"}
    )
    
    try:
        pairs = json.loads(response.choices[0].message.content)
        if isinstance(pairs, dict) and "pairs" in pairs:
            pairs = pairs["pairs"]
        return pairs
    except json.JSONDecodeError:
        return []


def create_sft_dataset(
    corpus_path: str,
    output_path: str,
    max_passages: int = 5000,
    system_message: str = "You are a knowledgeable scholar of Hindu scriptures."
):
    """
    Create full SFT dataset from corpus using synthetic generation.
    """
    sft_data = []
    
    with open(corpus_path, 'r', encoding='utf-8') as f:
        for i, line in enumerate(f):
            if i >= max_passages:
                break
            
            doc = json.loads(line)
            passage = doc['text'][:2000]  # Limit passage length for API
            source = doc.get('source', 'unknown')
            
            print(f"Processing passage {i+1}/{max_passages}...", end='\r')
            
            # Generate Q&A pairs
            pairs = generate_sft_pairs(passage, source)
            
            for pair in pairs:
                sft_example = {
                    "messages": [
                        {"role": "system", "content": system_message},
                        {"role": "user", "content": pair["question"]},
                        {"role": "assistant", "content": pair["answer"]}
                    ]
                }
                sft_data.append(sft_example)
    
    # Save dataset
    with open(output_path, 'w', encoding='utf-8') as f:
        for example in sft_data:
            f.write(json.dumps(example, ensure_ascii=False) + '\n')
    
    print(f"\n✓ Generated {len(sft_data)} SFT examples → {output_path}")


# Alternative: Template-based generation (cheaper, faster)
def template_based_sft(verse_data: List[Dict]) -> List[Dict]:
    """
    Generate SFT data from structured verse data using templates.
    No API calls needed — uses predefined question templates.
    """
    templates = [
        "Explain the meaning of this verse: {verse}",
        "What is the significance of {verse_ref} in {scripture}?",
        "{verse_ref} का अर्थ समझाइए।",
        "What philosophical concept does {verse_ref} teach?",
        "इस श्लोक का हिंदी अनुवाद दीजिए: {verse}",
        "How does {verse_ref} relate to daily life?",
    ]
    
    sft_data = []
    
    for verse in verse_data:
        import random
        template = random.choice(templates)
        
        question = template.format(
            verse=verse.get('sanskrit', ''),
            verse_ref=verse.get('reference', ''),
            scripture=verse.get('scripture', '')
        )
        
        answer = f"""**{verse.get('reference', '')}**

**Sanskrit:** {verse.get('sanskrit', '')}

**Translation:** {verse.get('translation', '')}

**Commentary:** {verse.get('commentary', '')}"""
        
        sft_data.append({
            "messages": [
                {"role": "system", "content": "You are a knowledgeable scholar of Hindu scriptures."},
                {"role": "user", "content": question},
                {"role": "assistant", "content": answer}
            ]
        })
    
    return sft_data

⚖️ DPO (Preference Alignment) Format

What It Is

DPO data teaches the model which responses are better than others. Each example has a prompt, a chosen (good) response, and a rejected (bad) response. The model learns to generate responses more like "chosen" and less like "rejected".

Format Specification

# Format: Explicit prompt with chosen/rejected responses

# Standard format
{
  "prompt": "What is Karma according to Hindu philosophy?",
  "chosen": "Karma (कर्म) in Hindu philosophy refers to...[detailed, accurate answer]",
  "rejected": "Karma is just about fate and destiny...[oversimplified or inaccurate]"
}

# Conversational format (recommended for chat models)
{
  "prompt": [
    {"role": "user", "content": "What is Karma according to Hindu philosophy?"}
  ],
  "chosen": [
    {"role": "assistant", "content": "Karma (कर्म) in Hindu philosophy is a profound concept..."}
  ],
  "rejected": [
    {"role": "assistant", "content": "Karma basically means what goes around comes around..."}
  ]
}

How to Create DPO Data

💡 Four Methods to Create Preference Data
  1. Human Annotation: Experts rate pairs of responses (gold standard, expensive)
  2. Model-as-Judge: Use a stronger model (GPT-4, Claude) to evaluate responses
  3. Rejection Sampling: Generate multiple responses, pick best/worst based on criteria
  4. Contrastive Pairs: Intentionally create good vs flawed responses
"""
Generate DPO preference data using rejection sampling + model-as-judge.
"""
import json
from typing import List, Dict, Tuple

def generate_dpo_via_rejection_sampling(
    prompts: List[str],
    model_name: str = "google/gemma-3-27b-it",
    judge_model: str = "gpt-4o",
    num_samples: int = 4
) -> List[Dict]:
    """
    Generate DPO pairs using rejection sampling:
    1. For each prompt, generate N responses from the model
    2. Use a judge model to rank them
    3. Take best as 'chosen', worst as 'rejected'
    """
    from transformers import pipeline
    
    # Load your fine-tuned model (after SFT stage)
    generator = pipeline("text-generation", model=model_name, device="cuda")
    
    dpo_data = []
    
    for prompt in prompts:
        # Generate multiple responses
        responses = []
        for _ in range(num_samples):
            output = generator(
                prompt,
                max_new_tokens=1024,
                temperature=0.8,  # Higher temp for diversity
                do_sample=True,
                top_p=0.9
            )
            responses.append(output[0]['generated_text'])
        
        # Judge responses (using stronger model)
        best, worst = judge_responses(prompt, responses, judge_model)
        
        if best and worst and best != worst:
            dpo_data.append({
                "prompt": [{"role": "user", "content": prompt}],
                "chosen": [{"role": "assistant", "content": best}],
                "rejected": [{"role": "assistant", "content": worst}]
            })
    
    return dpo_data


def judge_responses(prompt: str, responses: List[str], judge_model: str) -> Tuple[str, str]:
    """Use a stronger model to identify best and worst responses."""
    
    judge_prompt = f"""Rate these responses to the question about Hindu scriptures.
    
Question: {prompt}

Responses:
{chr(10).join(f'{i+1}. {r[:500]}' for i, r in enumerate(responses))}

Criteria:
- Accuracy (factual correctness about scriptures)
- Depth (comprehensive explanation)
- Respectfulness (culturally sensitive)
- Clarity (well-structured, easy to understand)
- References (cites specific texts/verses)

Return JSON: {{"best": , "worst": , "reasoning": "..."}}
"""
    
    # Call judge model
    response = client.chat.completions.create(
        model=judge_model,
        messages=[{"role": "user", "content": judge_prompt}],
        temperature=0.1,
        response_format={"type": "json_object"}
    )
    
    result = json.loads(response.choices[0].message.content)
    best_idx = result["best"] - 1
    worst_idx = result["worst"] - 1
    
    return responses[best_idx], responses[worst_idx]


# Method 2: Contrastive pair generation (no API needed)
def create_contrastive_dpo(good_answers: List[Dict]) -> List[Dict]:
    """
    Create DPO pairs by degrading good answers into bad ones.
    Degradation strategies:
    - Remove citations/references
    - Oversimplify
    - Add factual errors
    - Make culturally insensitive
    """
    import random
    
    degradation_strategies = [
        lambda a: a.split('\n')[0],  # Only keep first line (oversimplify)
        lambda a: a.replace('॥', '').replace('।', ''),  # Remove Sanskrit markers
        lambda a: ' '.join(a.split()[:50]),  # Truncate severely
    ]
    
    dpo_data = []
    
    for item in good_answers:
        strategy = random.choice(degradation_strategies)
        rejected = strategy(item['answer'])
        
        dpo_data.append({
            "prompt": [{"role": "user", "content": item['question']}],
            "chosen": [{"role": "assistant", "content": item['answer']}],
            "rejected": [{"role": "assistant", "content": rejected}]
        })
    
    return dpo_data

✅ Dataset Validation

"""
Validate your datasets before training to catch format issues early.
"""
import json
from typing import List, Dict

def validate_sft_dataset(path: str) -> Dict:
    """Validate SFT dataset format and quality."""
    errors = []
    warnings = []
    stats = {"total": 0, "valid": 0, "languages": {"hi": 0, "en": 0, "sa": 0}}
    
    with open(path, 'r', encoding='utf-8') as f:
        for line_num, line in enumerate(f, 1):
            stats["total"] += 1
            
            try:
                example = json.loads(line)
            except json.JSONDecodeError:
                errors.append(f"Line {line_num}: Invalid JSON")
                continue
            
            # Check required structure
            if "messages" not in example:
                errors.append(f"Line {line_num}: Missing 'messages' field")
                continue
            
            messages = example["messages"]
            
            # Check message structure
            for msg in messages:
                if "role" not in msg or "content" not in msg:
                    errors.append(f"Line {line_num}: Message missing role/content")
                    break
                if msg["role"] not in ("system", "user", "assistant"):
                    errors.append(f"Line {line_num}: Invalid role '{msg['role']}'")
                    break
            
            # Check there's at least one user and one assistant message
            roles = [m["role"] for m in messages]
            if "user" not in roles:
                errors.append(f"Line {line_num}: No user message")
            if "assistant" not in roles:
                errors.append(f"Line {line_num}: No assistant message")
            
            # Check for empty content
            for msg in messages:
                if not msg["content"].strip():
                    warnings.append(f"Line {line_num}: Empty content for {msg['role']}")
            
            # Check response length
            assistant_msgs = [m for m in messages if m["role"] == "assistant"]
            for am in assistant_msgs:
                if len(am["content"]) < 20:
                    warnings.append(f"Line {line_num}: Very short assistant response")
            
            stats["valid"] += 1
    
    # Print report
    print(f"{'='*50}")
    print(f"Dataset Validation Report: {path}")
    print(f"{'='*50}")
    print(f"Total examples: {stats['total']}")
    print(f"Valid examples: {stats['valid']}")
    print(f"Errors: {len(errors)}")
    print(f"Warnings: {len(warnings)}")
    
    if errors:
        print(f"\n❌ First 5 errors:")
        for e in errors[:5]:
            print(f"  {e}")
    
    if warnings:
        print(f"\n⚠️  First 5 warnings:")
        for w in warnings[:5]:
            print(f"  {w}")
    
    return {"errors": errors, "warnings": warnings, "stats": stats}

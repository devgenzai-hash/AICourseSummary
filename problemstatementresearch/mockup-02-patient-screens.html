EHR Data Architecture — Key Design Decision Every journal entry is stored as a typed object: {category, value, unit, context, timestamp, notes, photoUrl}. Entries are vectorized alongside lab reports using the same pgvector pipeline. The AI agent then has a single unified query: "30 days of fasting sugar readings" or "headache entries correlated with meals" — no separate databases. The streak counter (🔥 14 days) is a habit-formation mechanic: once patients start logging daily, the data flywheel for AI personalization kicks in. Doctor also sees EHR history on the briefing card.
AI Agent Layer

Not a generic chatbot — an agent harness that ingests your complete longitudinal health picture: lab reports + daily EHR journal + medications + (Phase 2) wearable data + (Phase 3) genome scans. Why this changes everything Generic health apps give you the same tip 10 million people get. HealthBridge's agent queries YOUR sugar readings + YOUR late-dinner journal notes + YOUR doctor's consultation note + YOUR lab reports. The output is: "On days you walked before 7 AM, your fasting sugar was 22% lower than days you didn't." No generic app can say that.
AI Agent Technical Architecture — The Agent Harness Pattern Inspired by agentic harnesses like Claude Code. Each user query triggers a multi-step agent chain: (1) Intent classification — is this a "trend query", "correlation query", "lab explanation", or "medication query"? (2) RAG retrieval from personal pgvector store filtered by date range + data type. (3) LLM reasoning with retrieved context. (4) Response formatted per language preference. Future: add sub-agents for each data type (wearable agent, lab agent, journal agent) that collaborate to produce unified insights. The more data sources, the more the agent can surface non-obvious correlations — "your headaches correlate with high sugar AND low sleep the previous night" would require 3 data sources working together.

Care Plan Generation — AI Architecture Note The AI agent gets: (1) latest diagnosis from consultation note, (2) last 3 lab reports, (3) EHR journal history (what the patient actually eats / their exercise habits), (4) current medications (some medicines have diet interactions). The late-dinner insight ("⚠️ late meals after 8 PM") comes directly from the patient's own journal data — not a generic rule. A doctor can edit the AI-generated plan before it's sent. Plan updates via WhatsApp so patients don't need to open the app.

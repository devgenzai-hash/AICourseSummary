Implementation Note: Role-based routing Single Next.js app. After login, role is determined (patient / doctor / admin). Route to the correct layout shell. Shared components (ReportCard, AppointmentCard, PatientCard) work across all three roles — same component, different props and permissions. Context-based access control: doctor sees all clinic patients, admin sees business data, patient only sees their own. No separate apps to build.
